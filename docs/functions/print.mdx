---
title: "print"
description: "The `print` statement: displays what values resolve to, without playing them."
---

```text Syntax
print(value: steps | notes | chords, ...)
```

| Parameter | Type | May be |
| --- | --- | --- |
| `value` | `steps`, `notes` or `chords` | One or more arguments, separated by commas. Each is a typed value, a name, a value function call, or a bare value. Must be finite. Not a pattern, block or line. |

Displays each argument as written, with what it resolves to under the settings in effect. `print` produces no sound and takes no musical time. It is a statement, not a function: it returns nothing and cannot be nested. It stands at the top level of a cell or inside a top-level `with`, and nothing may follow its closing parenthesis on the line.

## Arguments

| Argument | Read as |
| --- | --- |
| `steps step_seq`, `notes note_seq`, `chords chart` | The type written. |
| A name | Its declared type. |
| An interval call on a name | The type of the name. |
| An `extend` call | `chords`. |
| A bare degree or note letter, `1`, `C`, or an interval call on one | `notes`. |
| A bare value that can only be one type, `Cmaj7`, `x-x-` | That type. |

Each argument has one type. The type keyword goes at the start of the argument, not inside a call.

## Output

One row per run of arguments with the same type: the type, then each value followed by its meaning in parentheses.

| Value | Shown as |
| --- | --- |
| Note | The note as written, then its pitch: `1(C3)`. A note written with its octave, such as `E4`, is shown alone. |
| Chord | The chord as written, then its tones: `C(C3 E3 G3)`. A degree also shows the chord's name: `4(F(F3 A3 C4))`. |
| Slash chord | The bass after a slash, among the tones: `C/E(C3 E3 G3/E2)`. |
| Steps | The hits, without silence: `x^`. |

Within a row, a comma separates one argument from the next. Holds, rests and bar lines are not shown. A value with no hits or notes shows `[]`. Under `transpose`, the parentheses show the sounding pitches.

```composer-nb Example
steps accents = x-^-
print(accents, notes 1 3 5, chords 1 4 | 5dom7, chords C/E)
```

```text Output
steps x^
notes 1(C3) 3(E3) 5(G3)
chords 1(C(C3 E3 G3)) 4(F(F3 A3 C4)) 5dom7(G7(G3 B3 D4 F4)), C/E(C3 E3 G3/E2)
```

## Last expression

```text Syntax
value_expr ::= "steps" step_seq | "notes" note_seq | "chords" chart | name | call
```

A value written as a statement of its own is displayed as if printed, when it is the last statement of the cell. Earlier ones are checked and not displayed, and so is one inside a `with`. A literal needs its type keyword; a name or a call on a name does not.

```composer-nb Example
notes riff = 1 3 5
fifth(riff)
```

```text Output
notes 5(G3) 7(B3) 9(D4)
```

## Errors

```composer-nb Invalid
print(1,)
```

```text Error
print needs a value for each argument: print(1, 2, 3)
```

```composer-nb Invalid
print(pattern { kick: x })
```

```text Error
print takes musical values, without braces
```
