---
title: "print"
description: "The `print` statement: displays what values resolve to, without playing them."
---

```text Syntax
print(value: steps | notes | chords, ...)
```

| Parameter | Type | May be |
| --- | --- | --- |
| `value` | `steps`, `notes` or `chords` | One or more arguments, separated by commas. Each is a typed value, a name, an interval call, or a bare value. Must be finite. Not a pattern, block or line. |

Displays each evaluated argument, with what it resolves to under the settings in effect. `print` produces no sound and takes no musical time. It is a statement, not a function: it returns nothing and cannot be nested. It stands at the top level of a cell or inside a top-level `with`, and nothing may follow its closing parenthesis on the line.

## Arguments

| Argument | Read as |
| --- | --- |
| `steps step_seq`, `notes note_seq`, `chords chart` | The type written. |
| `note(value)`, `chord(value)` | The constructor's type. |
| A name | Its declared type. |
| An interval call on a name | The type of the name. |
| A bare degree or note letter, `1`, `C`, or a call on one | `notes`. |
| A bare value that can only be one type, `Cmaj7`, `x-x-` | That type. |

Each argument has one type. Constructors such as `note(1)` and `chord(1)` establish it inside a call: `print(second(note(1)))`. A sequence may also use a `notes` or `chords` prefix at the start of the argument.

## Output

Print evaluates calls before displaying their results. One row holds consecutive arguments of the same type. Spaces separate values within an argument; commas separate arguments. Only the leading evaluated value is bold; arrows, chord names and pitches use regular weight.

| Value | Display |
| --- | --- |
| Note degree | **1** → C3 |
| Absolute pitch | **E4** |
| Chord degree | **4** → F → (F3 A3 C4) |
| Named chord | **C** → (C3 E3 G3) |
| Slash chord | **C/E** → (C3 E3 G3/E2) |
| Steps | **x^** |

Function calls and constructors never add display levels. Deeply nested calls still resolve to a degree, a chord name, and its pitches. Unusual unnamed harmonies display their evaluated tone set rather than an unevaluated function call.

Holds, rests and bar lines are omitted. Empty values show `[]`. Under `transpose`, resolved names and pitches reflect the sounding result.

```composer-nb Example
print(second(note(1)), second(chord(1)))
print(chord(1 4), chord(5))
print(second(modify(chord(1), sus2)))
```

```text Output
notes 2 → D3
chords 2 → Dm → (D3 F3 A3)
chords 1 → C → (C3 E3 G3) 4 → F → (F3 A3 C4), 5 → G → (G3 B3 D4)
chords 2sus2 → Dsus2 → (D3 E3 A3)
```

## Last expression

```text Syntax
value_expr ::= "steps" step_seq | "notes" note_seq | "chords" chart | name | call
```

A value written as a statement of its own is displayed as if printed, when it is the last statement of the cell. Earlier ones are checked and not displayed, and so is one inside a `with`. Use a constructor for a typed literal; names and calls preserve their types.

```composer-nb Example
notes riff = 1 3 5
fifth(riff)
```

```text Output
notes 5 → G3 7 → B3 9 → D4
```

## Errors

```composer-nb Invalid
print(1,)
```

```text Error
print needs a value for each argument: print(1, 2, 3)
```

```composer-nb Invalid
print(pattern { kick: x })
```

```text Error
print takes musical values, without braces
```
