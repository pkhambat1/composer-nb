---
title: "Keyboard shortcuts"
description: "Key bindings in the playground notebook."
---

The notebook has two modes. In edit mode, keys type into the selected cell. In command mode, keys act on the selected cell. `Enter` switches to edit mode and `Esc` switches to command mode.

## Running cells

Available in both modes.

| Key                           | Action                                                                  |
| ----------------------------- | ----------------------------------------------------------------------- |
| `Shift+Enter`                 | Run the cell and select the next one. Inserts a new cell after the last. |
| `Ctrl+Enter` or `Cmd+Enter`   | Run the cell and keep it selected.                                      |
| `Alt+Enter`                   | Run the cell and insert a new music cell below.                         |

## Command mode

| Key          | Action                                      |
| ------------ | ------------------------------------------- |
| `Enter`      | Edit the selected cell.                     |
| `J` or `↓`   | Select the next cell.                       |
| `K` or `↑`   | Select the previous cell.                   |
| `A`          | Insert a music cell above.                  |
| `B`          | Insert a music cell below.                  |
| `D` `D`      | Delete the selected cell. The second press must follow within 400 ms. |
| `Z`          | Undo the last delete.                       |

## Edit mode

| Key                         | Action                                                           |
| --------------------------- | ---------------------------------------------------------------- |
| `Esc`                       | Leave edit mode.                                                 |
| `Tab`                       | Indent by two spaces. With a selection, indents each selected line. |
| `Shift+Tab`                 | Outdent the selected lines.                                      |
| `Enter`                     | New line at the current indentation. One level deeper after `{`. |
| `Ctrl+/` or `Cmd+/`         | Toggle `//` on the selected lines.                               |
