`time` and `tempo` apply to everything a cell plays, drums and chords alike. Both are [settings](/reference/settings): a word followed by its value, in effect from the line where it is written.

| Setting           | Value                 | Default    |
| ----------------- | --------------------- | ---------- |
| [`time`](#time)   | `<count> over <unit>` | `4 over 4` |
| [`tempo`](#tempo) | Number, 20 to 400     | `120`      |

## time

```text
time <count> over <unit>
```

| Parameter | Type                                 | Description                                                                                         |
| --------- | ------------------------------------ | --------------------------------------------------------------------------------------------------- |
| `count`   | Positive whole number, or a sum      | Notes per bar. A sum such as `3+4` gives the same bar length as `7` and sets the grouping shown in the drum grid. |
| `unit`    | `1`, `2`, `4`, `8` or `16`           | The note value being counted.                                                                       |

A bar lasts `count × 4 / unit` beats, where a beat is a quarter note. A bar cannot be longer than 8 whole notes.

`over` is required. `time 7/8` is an error, because `7/8` is the number 0.875. `6 over 8` and `3 over 4` have the same bar length and are distinct values.

<Cell>

```composer-nb
time 3+4 over 8
play { kick: x--x--- }
```

</Cell>

For the number of beats and steps in a bar of each time, see [Units](/reference/numbers-and-lengths#units).

## tempo

```text
tempo <number>
```

Quarter notes per minute, from 20 to 400. Decimals are accepted.

## Errors

| Message                                                                        | Cause                                             |
| ------------------------------------------------------------------------------ | ------------------------------------------------- |
| `tempo is quarter notes per minute, between 20 and 400`                        | Value out of range or not a number.               |
| `/ is division, so 7/8 is the number 0.875, not a time. Write time 7 over 8`   | `time` written as a fraction.                     |
| `The second number of time is the note being counted: 1, 2, 4, 8 or 16`        | Invalid `unit`.                                   |
