A pattern is a named piece of a song: a drum groove, a chord progression with its beat, a fill, a whole verse. Its lines start together and repeat until the pattern ends. A pattern does not sound until it is [played](/song/play).

| To write                                   | Use                                                  |
| ------------------------------------------ | ---------------------------------------------------- |
| A drum groove that loops                   | A pattern of [drum lines](/drums/lines).             |
| A guitar riff or a bass line over a drum groove | A pattern holding a [note line](/pitched/notes) and the drum lines. See [A riff and drums together](#a-riff-and-drums-together). |
| Chords over a drum groove                  | A pattern holding a [chord line](/pitched/chords) and the drum lines, or the groove's name. See [Chords and drums together](#chords-and-drums-together). |
| A fill, or any bar that differs            | [`bar`](#bar) inside the pattern.                    |
| The order of the song                      | A [sequence line](#sequence-lines): `intro verse chorus`. |

## Syntax

```text
pattern <name> = [<length>] { <statements> }
pattern <name> = <sequence>
pattern <name> = [<length>] <statement>
```

| Part         | Description                                                                                         |
| ------------ | --------------------------------------------------------------------------------------------------- |
| `name`       | See [Names](/reference/names#names).                                                          |
| `length`     | Optional. A number of `bars`. Sets the pattern's duration.                                          |
| `statements` | Instrument lines, sequence lines, [`bar`](/song/patterns#bar), [`every`](/drums/note-values), settings and declarations. |
| `sequence`   | Pattern names in a row. See [Sequence lines](#sequence-lines).                                      |

A pattern without a name is written as a bare block, with an optional length in front, anywhere a pattern name is accepted.

<Cell>

```composer-nb
time 7 over 8

pattern groove = {
  kick: x--x---
  snare: ----x--
  ride.bell: x--
}

play groove { snare: xxxxxxx } groove
```

</Cell>

## Body

| Statement in the body           | Behavior                                                              |
| ------------------------------- | --------------------------------------------------------------------- |
| Instrument line                 | Repeats until the pattern ends.                                       |
| Sequence line                   | Plays its items in order, then repeats until the pattern ends.        |
| `bar <n> ...`                   | Plays in that bar on each pass through the pattern.                   |
| `every <length> ...`            | Repeats until the pattern ends, at that step duration.                |
| Setting or declaration          | Local to the pattern.                                                 |

`play` is not accepted inside a block.

## Duration

| Pattern                 | Duration                                                                                                   |
| ----------------------- | ---------------------------------------------------------------------------------------------------------- |
| With a length           | The length.                                                                                                |
| Without a length        | The least common multiple of the durations of everything that repeats in it: the point where its lines all end together. |
| Without a length, containing `bar <n>` | As above, extended by whole multiples until it contains bar `n`.                            |

In the example above, the kick and snare are 7 steps and the bell is 3 steps, so `groove` lasts 21 steps: one and a half bars of `7 over 8`.

<img src="/images/lines-line-up.svg" alt="Step grid in 7 over 8. The kick and snare repeat every 7 steps and the ride bell every 3. All three end together after 21 steps." />

A pattern without a length whose lines first end together after more than 64 bars is an error. Give it a length.

## Fit rule

Everything that repeats must fit the duration of what contains it a whole number of times. This applies to lines in a pattern, to patterns repeated by a length, and to patterns repeated in a play without a length. A play's own length cuts what plays there instead. See [play](/song/play#duration).

```composer-nb Invalid
time 7 over 8

pattern groove = 4 bars {
  kick: x--x---
  ride.bell: x--
}

play groove
```

```text
The ride.bell line is 3 steps long, which doesn't fit 4 bars a whole number of times. The things repeating here line up every 3 bars
```

The message reports the shortest duration at which everything fits. Fit is checked when the pattern is played, so a pattern that is declared and never played does not report it.

## A riff and drums together

A guitar, bass or piano part goes in the same pattern as the drums, on a line of its own. A [note line](/pitched/notes) is drawn on the same steps as a [drum line](/drums/lines), with a note where the drum has its `x`, so the two read against each other step for step.

<Cell>

```composer-nb
time 7 over 8
tempo 100
octave 2

pattern groove = {
  kick: x--x---
  snare: ----x--
  ride.bell: x--
  guitar.electric: E---F# E-E--
}

play {
  crash: 1
  groove
}
```

</Cell>

`octave 2` puts every note written without a number in octave 2, so the riff starts on `E2`, a guitar's low E string. The same riff with the octave on each note is `E2---F#2 E2-E2--`.

Every line starts at the beginning of the pattern and repeats at its own length. Lines of different lengths drift against each other and come back together later.

| Line              | Lasts    | Plays in `groove` |
| ----------------- | -------- | ----------------- |
| `kick`, `snare`   | 7 steps  | 30 times          |
| `ride.bell`       | 3 steps  | 70 times          |
| `guitar.electric` | 10 steps | 21 times          |

`groove` has no length, so it lasts until all of its lines end together: 210 steps, the least common multiple of 7, 3 and 10. A `7 over 8` bar is 14 steps, so that is 15 bars. The play has no length either, so it lasts as long as `groove`, and its own `crash` line plays once. See [Duration](#duration).

| To                                               | Write                                                                              |
| ------------------------------------------------ | ---------------------------------------------------------------------------------- |
| Start the riff again with every bar              | The riff a bar long, with `-` to the end of the bar: `E---F# E-E------`.            |
| Stop the last note before the riff comes round   | `_` where it stops: `E---F# E-E_-`.                                                 |
| Play short notes instead of ringing ones         | `_` after each note: `E_--F# E_E_-`.                                                |
| Play the riff an octave higher                   | `octave 3` above the pattern, which is also what it is with no `octave` line.      |
| Play for a set time                              | A length that every line fits: `play 15 bars { ... }`, or `30 bars`. See the [fit rule](#fit-rule). |
| Hear the drums or the riff alone                 | `//` in front of the other lines.                                                  |

## Chords and drums together

A [chord line](/pitched/chords) and drum lines go in the same pattern. They start together, and each repeats on its own. The chords play on the [instrument](/pitched/instruments#instruments) whose line they are on, so a `guitar` line makes the part a guitar.

<Cell>

```composer-nb
pattern verse = {
  guitar: chords Am F|C G
  kick: x---x---
  snare: ----x---
  hat: x-
}

play 4 bars verse
```

</Cell>

The chords last two bars and each drum line divides two bars, so `verse` lasts two bars and the play repeats it twice.

A groove with a name of its own goes under the chords by name. The same groove can then sit under each section's chords.

<Cell>

```composer-nb
time 7 over 8
tempo 100

pattern groove = {
  kick: x--x---
  snare: ----x--
  ride.bell: x--
}

pattern verse = {
  guitar: chords Dm|Bb|C
  groove
}

play verse
```

</Cell>

| Part of `verse` | Lasts                          | Plays in `verse` |
| --------------- | ------------------------------ | ---------------- |
| The chord line  | 3 bars, which is 42 steps      | Once             |
| `groove`        | 21 steps, one and a half bars  | Twice            |

`verse` ends where its parts end together, after three bars. The rules are the ones for any lines: [Duration](#duration) when the pattern has no length, and the [fit rule](#fit-rule) when it has one. A chord line always lasts a whole number of bars. A drum line or a note line lasts as many steps as it has, and a drum line written as beats lasts one bar.

## bar

`bar` puts lines in one bar, or a range of bars, of the pattern or play that contains it: a fill in bar 4, a crash in bar 1, a different chord in the last bar.

```text
bar <n> <statement>
bar <n> { <statements> }
bar <n> to <m> <statement>
bar <n> to <m> { <statements> }
```

| Parameter   | Type                      | Description                                                              |
| ----------- | ------------------------- | ------------------------------------------------------------------------ |
| `n`         | Whole number, 1 to 64     | The bar, counted from 1 from the start of the containing pattern or play. |
| `m`         | Whole number, `n` to 64   | The last bar of a range. The range includes both ends.                   |
| `statement` | Instrument line or sequence line | What plays in those bars.                                         |

`bar` is valid inside a pattern or a play. It is an error at top level.

### What bar does

| Aspect      | Behavior                                                                                                         |
| ----------- | ---------------------------------------------------------------------------------------------------------------- |
| Content     | The statements form a pattern that lasts exactly the named bars. Each one repeats to fill them and must fit a whole number of times. |
| Placement   | The content starts at the beginning of bar `n` on each pass through the containing pattern or play.              |
| Mixing      | The content is added to what the containing block plays in those bars. It does not silence other lines.          |
| Precedence  | A `bar` statement counts as a lower line. Where it hits the same instrument at the same moment as a line above it, the `bar` content is used. See [Simultaneous hits](/drums/lines#simultaneous-hits). |

### Effect on duration

| Containing block          | Effect                                                                         |
| ------------------------- | ------------------------------------------------------------------------------ |
| Pattern without a length  | The pattern is extended in whole multiples of its duration until it contains bar `m`. |
| Pattern or play with a length | The length must contain bar `m`. Otherwise it is an error.                 |
| Play without a length     | The play lasts at least to the end of bar `m`.                                 |

### A fill in the second bar

<Cell>

```composer-nb
time 7 over 8
tempo 90

pattern groove = {
  kick: x--x---
  snare: 2e 4
  snare.ghost: --x----
  hat: ^-x-
  bar 2 {
    snare.ghost: 2 beats rest, dd, 1 beats rest
    hat.open: 2 beats rest, --^-, 2 steps rest
    hat.pedal: 4
  }
}

play 6 bars {
  crash: 1
  groove
}
```

</Cell>

`groove` has no length. Its lines end together after 28 steps, which is two bars of `7 over 8`, so it already contains bar 2. The `snare.ghost` line in `bar 2` replaces the outer `snare.ghost` hit that falls on the same moment and leaves the others in place.

<img src="/images/one-bar-only.svg" alt="A two-bar groove. The kick, snare, ghost note and hi-hat lines repeat in both bars. A bar 2 block adds a burst of doubles, an open hi-hat and a pedal close in bar 2 only." />

## Sequence lines

```text
<item> [<item>] ...
<item> = [<length>] <name>
       | [<length>] { <statements> }
       | [<length>] ( <item> ... )
```

A sequence line plays its items one after another.

| Item                    | Meaning                                                            |
| ----------------------- | ------------------------------------------------------------------ |
| `verse`                 | Plays the pattern once.                                            |
| `verse verse`           | Plays it twice.                                                    |
| `{ ... }`               | Plays a pattern without a name once.                               |
| `4 bars verse`          | Repeats the pattern for 4 bars.                                    |
| `8 bars (verse chorus)` | Repeats the group `verse` then `chorus` for 8 bars.                |

<Cell>

```composer-nb
pattern intro = { crash: 1 }
pattern verse = { kick: x---x--- }
pattern chorus = {
  kick: x-x-
  snare: ----x---
}

play intro 4 bars (verse chorus) intro
```

</Cell>

A sequence line is valid in a block, after `play`, and as the value of a `pattern` declaration. `*` is not a repetition operator; use a length.

## Patterns inside patterns

A pattern can play other patterns by name. A pattern cannot play itself, directly or through another pattern.

<Cell>

```composer-nb
pattern beat = {
  hat: x-
  kick: x---
}

pattern verse = 4 bars {
  piano: chords Am F|C G
  beat
}

play verse
```

</Cell>

## Evaluation

A pattern is evaluated each time it is played, with the settings and names in effect at that point. The same pattern played after `tempo 60` and after `tempo 120` has different durations in seconds. See [Scope](/reference/program-structure#scope).

## Errors

| Message                                                                                                    | Cause                                               |
| ---------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| `A pattern gets its name with =: pattern groove = { ... }`                                                 | `pattern groove {` without `=`.                     |
| `groove needs a type and = to name its braces: pattern groove = {`                                         | `groove {` without a type.                          |
| `Nothing plays this pattern. Put play in front: play { ... }`                                              | A bare block at top level.                          |
| `"outro" isn't defined. Patterns so far: intro, verse`                                                     | Unknown name on a sequence line.                    |
| `groove plays itself, so it would never end`                                                               | Recursive pattern.                                  |
| `groove has nothing to play`                                                                               | A body with no instrument, sequence, `bar` or `every` statement. |
| `A length goes in front of what it measures: pattern groove = 4 bars {`                                    | Length written after the block.                     |
| `* only multiplies numbers. To repeat, put a length in front: 4 bars groove`                               | `groove * 2`.                                       |
| `What's in groove only lines up again after more than 64 bars. Say how long it is: pattern groove = 4 bars {` | No length, and the lines do not end together within 64 bars. |
| `play goes at the top, not inside braces`                                                                  | `play` inside a block.                              |
| `bar takes the number of a bar, then what plays there: bar 2 { ... }, or bar 3 to 4 { ... }`    | No bar number.                                |
| `bar 2 needs what plays there: bar 2 { ... }`                                                   | Nothing after the bar number.                 |
| `Bars are counted from 1, up to 64: bar 1, bar 2`                                               | Bar number below 1, above 64 or not whole.    |
| `bar 4 to 3 runs backwards. The first bar comes first`                                          | `m` less than `n`.                            |
| `groove is 1 bar long, so it has no bar 2`                                                      | The containing block's length excludes the bar. |
| `bar 2 { ... } goes inside a pattern or a play, to say where in it`                             | `bar` at top level.                           |
| `bars is a length, and goes after a number: 6 bars groove. To say which bars, write bar: bar 3 to 4 { ... }` | `bars` used in place of `bar`.   |
