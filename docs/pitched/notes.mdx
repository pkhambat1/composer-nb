title: "notes"
description: "The `notes` type: one voice of single notes, dividing each bar evenly like chords."
---

```text Syntax
note_seq  ::= note_item+ [note_fill]
note_item ::= note_word | name | call | repeat | "|"
note_word ::= attack ("-" | "_")* | ("-" | "_")+
attack    ::= ["^" | "~"] pitch
pitch     ::= letter ["#" | "b"] [octave] | degree | numeral
repeat    ::= integer "*" (note_word | name | call | "(" note_item+ ")")
call      ::= ["^" | "~"] interval "(" note_seq ["," integer] ")"
note_fill ::= "..." (pitch | "-")
```

A `notes` value is a melody or bass line: one note at a time, written in bars. It names no instrument: the [instrument line](/pitched/instruments#instrument-lines) it is written on decides what plays it. Several voices at once are [layers](/pitched/instruments#layers) on that line.

## Where a notes value is written

| Position | Signature | Notes |
| --- | --- | --- |
| On an instrument line | `instrument ":" "notes" note_seq` | Use `note(value)` or a typed name directly; a whole sequence may use the `notes` prefix. |
| In a declaration | `"notes" name "=" note_seq` | Must be finite: no `note_fill`. |
| As a function argument | `interval "(" note_seq ")"` | Must be finite. |
| In `print`, or as a last expression | `"notes" note_seq`, or a `notes` name | Must be finite. |

## What a notes value is made of

| Form | Example | Meaning |
| --- | --- | --- |
| Note word | `C4`, `1---`, `b3-_` | A note, then any holds and rests. |
| Hold and rest | `-`, `_` | `-` holds the note for one more step. `_` stops it; the step is silent. |
| Name | `riff` | The notes of a declared `notes` name, in place. |
| Interval call | `octave(riff)`, `fifth(1 3)` | The argument, moved through the scale; see [Interval functions](/functions/intervals). |
| Repeat | `4*1`, `2*(1-3-)`, `2*riff` | The word, name, call or group, that many times in a row. |
| Bar line | `\\|` | Separates bars. The notes, holds and rests in each bar divide it evenly. |
| Fill | `...-`, `...5` | Last on the line: holds or sounds a note to the end of the surrounding part. |

Items are separated by spaces, which take no time. Two notes may not touch: `F# E`, not `F#E`. A note may be followed directly by its holds and rests, and the next note may follow those: `1---3---`.

## Pitches

| Form | Syntax | Meaning |
| --- | --- | --- |
| Letter | `letter ["#" \\| "b"] [octave]` | An absolute pitch: `A` to `G`, an optional sharp or flat after the letter, an optional octave from 0 to 8. Without an octave, the [octave](/language/settings#octave) in effect. `C4` is middle C. |
| Degree | `["-"] ["b" \\| "#"] digit+` | A degree of the scale in effect: `1` is the tonic, `8` the tonic above, `-1` the scale tone below. The accidental comes before the number. See [Degrees](/pitched/key#degrees). |
| Numeral | `["b" \\| "#"] ("i" … "vii")` | A lowercase Roman numeral: the same as degrees 1 to 7. |

All the digits of a degree belong to it: `13` is degree thirteen, and `1 3` is two notes. A minus sign is a negative degree only at the start of a note word; anywhere else it is a hold. So `-1---` starts on the tone below the tonic, and in `1---2---` every dash is a hold.

Every pitch must be within MIDI 0 to 127 after interval functions and [transpose](/language/settings#transpose).

```composer-nb Example
print(notes C E4 F#2 Bb, notes 1 3 b3 8 -1, notes i iii v)
```

```text Output
notes C → C3 E4 F#2 Bb → Bb3, 1 → C3 3 → E3 b3 → Eb3 8 → C4 -1 → B2, 1 → C3 3 → E3 5 → G3
```

## Steps, holds and rests

Each note, hold and rest occupies one slot, however many characters the note takes to write. The slots in each bar divide that bar evenly, just as they do in `chords`: in `4 over 4`, `1 2 3 4` is four quarter notes, `1 5` is two half notes, and `1` is a whole note. Without a bar line, the entire value is one bar; with bar lines, each bar divides independently.

```composer-nb Example
play(piano: notes 1 2 3 4 | 5 6 7 8 | 8 7 6 5 | 4 3 2 1)
```

As with chords, slots must occupy whole ticks at 96 ticks per beat. Three equal notes in 4/4 are valid. For a fixed step length, triplets or a riff shorter than a bar, use [every](/language/patterns#every): `play every 1/4 beats piano: notes 1 2 3` plays three sixteenth notes. Inside `every`, `|` fills the rest of the bar with silence; the final incomplete bar is padded too.

| Token | Effect on its slot |
| --- | --- |
| A pitch | Starts a note. |
| `^` before a pitch or call | Starts it accented. |
| `~` before a pitch or call | Starts it soft. |
| `-` | The note sounding keeps sounding. Silent if nothing is sounding. |
| `_` | The note sounding stops. The slot is silent. |

A note sounds until the next note, the next `_`, or the end of the part. In a repeating pattern, a note still held at the end of the line rings into the repeat until the line's first note or rest.

```composer-nb Example
play(piano: notes C4--- E4-_- ^G4- ~G4- C5---)
```

## Length

| Form | Slots contributed |
| --- | --- |
| Note word | One per note, hold and rest. |
| Name | The length of the named value. |
| Interval call | The length of its argument. |
| `n*item` | `n` times the length of `item`. |
| `\\|` | 0. |
| Fill | None of its own; see [Fills](/pitched/notes#fills). |

A finite `notes` value may be at most 64 bars long. Names and interval calls insert their slots and bar lines in place; use `phrase | third(phrase)` to put two phrases in separate bars. Repeats copy slots, so `8*1` plays eight eighth notes in one `4 over 4` bar, while `2*(1 3 |)` plays two bars of half notes.

## Repeats

```text Syntax
repeat ::= integer "*" (note_word | name | call | "(" note_item+ ")")
```

| Operand | Type | May be |
| --- | --- | --- |
| `integer` | `integer` | A literal of at least 2. |
| Right-hand side | `notes` | A note word, a `notes` name, an interval call, or a parenthesized group of items. Groups nest. |

Plays its right-hand side `integer` times in a row. A repeat copies what it is given: `8*1` is eight separate notes, `1 7*-` is one note held for eight steps, and `8*_` is eight silent steps. Parentheses in notes always need a count.

A pattern may repeat attacks within a bar: `4*1` is four notes, not one long note. Explicit repetition is valid in both patterns and blocks. Finite fixed-step lines are padded to complete bars before they repeat; see [Explicit repetition](/drums/steps#explicit-repetition).

```composer-nb Example
print(notes 2*(1 3) 5 3*-)
```

```text Output
notes 1 → C3 3 → E3 1 → C3 3 → E3 5 → G3
```

## Fills

```text Syntax
note_fill ::= "..." (pitch | "-")
```

| Fill | Effect |
| --- | --- |
| `...-` | The note sounding is held to the end of the surrounding part. |

| `...pitch` | That note starts and is held to the end. |

A fill is the last item on a line and has no length of its own: another finite line, or an explicit length, must say when the part ends. It starts after the written bars (or after the fixed steps inside `every`); with no prefix it starts immediately. A value with a fill cannot be named, printed or passed to a function.

```composer-nb Example
play(piano: notes 1 3 5 - ...-) for 2 bars
```

## Interval calls

```text Syntax
call ::= ["^" | "~"] interval "(" note_seq ["," integer] ")"
```

An interval call inside `notes` has type `notes` and stands wherever a note word may. Its argument is any finite `note_seq`. An accent or ghost mark before the call applies to every note in it. The functions are defined in [Interval functions](/functions/intervals).

```composer-nb Example
notes riff = 1-3-
print(notes riff fifth(riff) octave(riff, -1))
```

```text Output
notes 1 → C3 3 → E3 5 → G3 7 → B3 -7 → C2 -5 → E2
```

## Errors

```composer-nb Invalid
play piano: notes F#E
```

```text Error
"F#E": notes don't touch, so put a space between them: F# E
```

```composer-nb Invalid
play piano: notes 1 rest 3
```

```text Error
A silent note step is _. Repeat silence with 8*_; unfinished bars fill with silence
```

```composer-nb Invalid
play piano: notes (1 3)
```

```text Error
Parentheses in notes need a repeat count: 2*(1--- 3---)
```

```composer-nb Invalid
play piano: notes C9
```

```text Error
"C9": octaves run from 0 to 8
```
