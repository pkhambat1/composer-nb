An [instrument](/pitched/instruments)'s line holds a `notes` value when the word `notes` comes first: `bass: notes i---v---`. It is drawn on steps, and a step is a sixteenth note, so a bar of `4 over 4` is 16 steps.

```composer-nb
play piano: notes E4---E4---F4---G4--- | G4---F4---E4---D4---
```

## Writing notes

A note is a capital `A` to `G`, then an optional `#` or `b`, then an optional octave from 0 to 8. A note without a number is in the current [`octave`](/pitched/instruments#octave). Pitches are as they sound, so a guitar's low E is `E2`.

| Step | Plays |
| --- | --- |
| A note, a [degree](#degrees) or an [interval function](#interval-functions) | Starts the note. It sounds until the next note or `_`. |
| `^` or `~` before a note | The note accented, or soft. |
| `-` | Nothing new. A sounding note carries on. |
| `_` | Stops the note: one step of silence. |
| `\|` | Optional bar line, checked against the `time`. |

A note is one step however many characters it has, so `F---` and `F#---` are both quarter notes. Two notes never touch: a `-`, `_`, space or `|` goes between them. A space takes no step, so `E---F# E-E--` is ten steps.

In a pattern, the last note rings over the repeat until the first note or `_`. Write each pattern line's repeating figure once: `C2-C2-` is an error there because `C2-` already repeats. A block, a direct `play` line, or a named `notes` phrase can contain finite repeats.

## Degrees

A positive integer is a degree of the [`key`](/pitched/key) and its mode: in C major `3` is E, and in C minor it is Eb. `b` or `#` before a degree moves it a semitone off the scale. Degree `1` is the root in the current `octave`. Count past the end of the scale to continue into the next octave: in seven-note modes `8` is the next tonic and `15` is two octaves up. In six-note `wholeTone`, those tonics are `7` and `13`; `8` is its second degree in the next octave.

Negative degrees count downward from the tonic, skipping zero. In C major, `-1` is B below C, `-2` is A, `-7` is the lower C, and `-14` is C two octaves down. Each mode uses its own scale: in six-note `wholeTone`, `-6` reaches the lower tonic. Put the sign before an accidental: `-b1` lowers the note at degree `-1` by a semitone.

A leading minus belongs to the degree. Dashes inside a note word still sustain, so separate negative notes with spaces: `-1--- -2---`. The existing `1---2---` keeps its timing, and a standalone `-` remains a sustain.

All consecutive digits form one degree: `13` is the thirteenth degree, while `1 3` is two notes. Lowercase Roman numerals remain accepted within the first octave. `octave(phrase, -2)` lowers a whole phrase two octaves. Apostrophe notation is no longer accepted. Notes must fit the playable MIDI range, 0 to 127.

```composer-nb
set octave 4

notes scale = 1---2---3---4---|5---6---7---8---

play piano: notes scale
with mode minor { play piano: notes scale, }

set key F#
play piano: notes scale
```

A name holds degrees, so it is read under whichever key and mode play it. Letters and degrees can share a line. Numbers on a drum line are not notes; kit pieces use their step characters.

## Interval functions

`fifth(value)` moves each note four positions up the active scale. `second`, `third`, `fourth`, `sixth`, `seventh`, `octave`, and `ninth` through `fifteenth` work the same way; `unison` leaves it in place. An octave always spans the whole scale, including six-note `wholeTone`.

The argument can be a single note, an inline phrase, or a named phrase. Holds, rests, accents and bar lines keep their timing. An optional integer count repeats the move: `fifth(1, 2)` replaces `fifth(fifth(1))`, and `fifth(1, -1)` moves down a fifth. Counts range from -64 to 64. Step repeats work inside a function: `fifth(1 7*- 3 7*-, 2)` moves two held notes up two fifths.

```composer-nb
notes phrase = ^1--- 3--- 5--- 7---
notes answer = fifth(phrase)

play piano: notes phrase answer
with mode minor { play piano: notes answer, }
play piano: notes fifth(1) 7*- fifth(1, 2) 7*-
```

Functions use the active key and mode, not a fixed semitone distance: `fifth(B3)` is F4 in C major. A chromatic offset is carried relative to the scale: `fifth(Bb3)` is Fb4 in C major, because both notes are one semitone below their scale degree. For letters missing from a six-note scale, movement counts from the preceding spelled scale degree and carries the pitch offset. [`chords`](/pitched/chords#interval-functions) uses the same rule for every chord tone and the bass.

## Repeats and holds

`n*word` repeats a note word, and `n*(words)` repeats a group. Counts are whole numbers of at least two, and groups can nest: `2*(1 7*- 3 7*-)`. A word can also be a named `notes` phrase or an interval function. Spaces separate words; commas separate brace entries or function arguments.

Repeats copy attacks as well as holds: `8*1` plays eight notes, while `1 7*-` starts one note and sustains it for seven more steps. At the default sixteenth-note grid that is two beats. `8*_` is eight silent steps. [`every`](/language/patterns#every) changes the duration of every step, including those inside a repeat. Note values no longer take `beats`, `steps`, `bars`, `rest`, or comma-separated duration lists.

A final `...G1` starts G1 and holds it to the end of the block, `...-` sustains the preceding note, and `..._` fills with silence. Another line or an explicit block length must supply the end. A fill cannot go inside a bounded repeat or an interval function.

```composer-nb
set time 3 over 4

pattern waltz = {
  bass: notes C2 11*- G1 11*-,
  piano: chords _ C C|_ G G,
}

play waltz for 2 bars
play piano: notes 8*_ E4---F4--- G4 11*-
```

A long line continues on the next line when that line starts with `|`. Bar lines check the expanded steps against the current time signature.

```composer-nb
notes flats = A3-Ab3-G3-Gb3-F3-E3-Eb3-D3-
  |Db3-C3-B2-Bb2-A2--- 4*_

play piano: notes flats
```

## Layers

A line plays one note at a time. For notes that sound together, give the instrument a block of layers, one per line. Each layer is its own voice and repeats until they all end together. A layer can be a chart with `chords` in front, to put chords under a tune.

```composer-nb
set octave 4

play piano: {
  chords vi iv|i v,
  notes vi-------iv-------|vi---v---iv---iii---,
}
```
