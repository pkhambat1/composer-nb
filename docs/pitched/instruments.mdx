A pitched instrument plays [notes](/pitched/notes) and [chords](/pitched/chords). Each one has a line of its own, like a drum. Three [settings](/reference/settings) change what those lines play. None of them affects drums.

| Setting             | Value                 | Default | Effect                                                     |
| ------------------- | --------------------- | ------- | ---------------------------------------------------------- |
| [`key`](#key)       | Key name              | `C`     | The key that Roman numerals are read in.                   |
| [`capo`](#capo)     | Whole number, 0 to 12 | `0`     | Raises a guitar's chords by that many frets.               |
| [`octave`](#octave) | Whole number, 1 to 6  | `3`     | The octave of a chord's root, and of a note with no number. |

## Instruments

| Name              | Source                                                                                                             |
| ----------------- | ------------------------------------------------------------------------------------------------------------------ |
| `piano`           | Sampled grand piano. Samples load from the network.                                                                |
| `piano.electric`  | Synthesized electric piano.                                                                                        |
| `organ`           | Synthesized organ.                                                                                                 |
| `pad`             | Synthesized pad with a slow attack.                                                                                |
| `bass`            | Synthesized bass.                                                                                                  |
| `guitar`          | Sampled steel-string guitar. Samples load from the network. Chords are played as fretboard shapes where a shape is known. |
| `guitar.electric` | Sampled clean electric guitar. Samples load from the network. Chords are played as fretboard shapes where a shape is known. |

The instrument is the name of the line. There is no setting for it.

```text
<instrument>: <notes>
<instrument>: chords <bars>
<instrument>: { <layer> ... }
```

| After the colon        | The line plays                                              | Reference                           |
| ---------------------- | ----------------------------------------------------------- | ----------------------------------- |
| Notes                  | Single notes, drawn on the steps.                           | [Note lines](/pitched/notes)        |
| `chords` and a chart   | Chords, written by the bar.                                 | [Chord lines](/pitched/chords)      |
| A block                | Its layers together: more notes at once, or chords under a tune. | [Layers](/pitched/notes#layers) |

A block holds one line for each instrument. Instruments play together on lines of their own.

<Cell>

```composer-nb
pattern verse = {
  guitar: chords Am - F -|C - G -
  bass: A1------F1------C2------G1------
  hat: x-
}

play verse
```

</Cell>

A drum name is not a pitched instrument. Drums are written as [drum lines](/drums/lines).

## key

```text
key <note>[m]
```

The key that [Roman numeral chords](/pitched/chords#roman-numerals) resolve against. `note` is a letter `A` to `G` with an optional `#` or `b`. A trailing `m` selects a minor key.

| Example  | Key            |
| -------- | -------------- |
| `key C`  | C major        |
| `key Am` | A minor        |
| `key Bb` | B flat major   |
| `key F#m`| F sharp minor  |

## capo

```text
capo <fret>
```

A whole number from 0 to 12. Each chord on a `guitar` or `guitar.electric` line sounds `fret` semitones higher than written. Chord labels and diagrams keep the written shape.

`capo` has no effect on other instruments, or on a guitar's [notes](/pitched/notes): a note's name is its pitch. A cell that sets a capo above 0 and plays, but plays no guitar chords, reports `capo only moves a guitar's chords. Give a guitar some: guitar: chords Am F|C G`. An inherited capo does not trigger this error.

<Cell>

```composer-nb
capo 2
play guitar: chords Am E7|G D
```

</Cell>

## octave

```text
octave <number>
```

A whole number from 1 to 6. Sets the octave of each chord's root, and of each [note](/pitched/notes#notes) written without a number of its own. The bass note of a chord is placed one octave below the root. Guitar chords played as fretboard shapes ignore this setting.

## Voicing

| Instrument                   | Voicing                                                                                                    |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------- |
| All but the guitars          | Chord tones stacked upward from the root in the current [`octave`](#octave), within two octaves. The bass note sounds one octave below. |
| `guitar`, `guitar.electric`  | The fretboard shape for the chord where one is known, shifted up by [`capo`](#capo). Otherwise as above. |

## Errors

| Message                                                                                         | Cause                                             |
| ----------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| `"banjo" isn't an instrument. Instruments: guitar, guitar.electric, piano, piano.electric, organ, pad, bass, crash, ...` | Unknown instrument name.  |
| `"guitar.acoustic" isn't an instrument. guitar's other sound is guitar.electric`                | Unknown sound after the dot.                      |
| `epiano is piano.electric now`                                                                  | The earlier name of the electric piano.           |
| `sound is gone. The instrument is the line's name now: guitar: chords Am F\|C G`                | The earlier `sound` setting.                      |
| `guitar is an instrument, so it takes a colon: guitar: chords Am F`                             | `=` after an instrument.                          |
| `key looks like C, Am, Bb or F#m`                                                               | Unknown key.                                      |
| `capo is a fret number from 0 to 12`                                                            | Value out of range or not whole.                  |
| `octave is a number from 1 to 6`                                                                | Value out of range or not whole.                  |
| `capo only moves a guitar's chords. Give a guitar some: guitar: chords Am F\|C G`               | `capo` set in a cell that plays no guitar chords. |
