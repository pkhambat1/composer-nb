## Instrument lines

```text Syntax
line    ::= instrument ":" pitched
          | instrument ":" "{" pitched ("," pitched)* [","] "}"
pitched ::= "notes" note_seq | "chords" chart
```

| Operand | Type | May be |
| --- | --- | --- |
| `instrument` | `instrument` | One of the 6 names in [Instruments](/pitched/instruments#instruments). |
| `note_seq` | `notes` | Note words, a `notes` name, repeats, interval calls, a fill; see [notes](/pitched/notes). |
| `chart` | `chords` | Chord symbols and degrees in bars, a `chords` name, interval calls; see [chords](/pitched/chords). |

An instrument line gives `notes` or `chords` to one instrument. `instrument` is a fixed name, not a value: it cannot be declared, assigned or passed to a function. Because an instrument takes either type, the line always says which: the keyword `notes` or `chords` follows the colon, before a literal and before a name, and a name must be of that type.

The line is a [part](/language/patterns#parts): it stands in a body or directly after `play`.

```composer-nb Example
notes walk = 1-3-5-3-
play pattern {
  bass: notes walk,
  piano: chords C | Am,
}
```

## Instruments

| Name | Instrument |
| --- | --- |
| `piano` | Grand piano. |
| `piano.electric` | Electric piano. |
| `organ` | Drawbar organ. |
| `bass` | Fingered electric bass. |
| `guitar` | Steel-string acoustic guitar. |
| `guitar.electric` | Electric guitar, `clean` or `muted`; see [guitar.electric](/language/settings#guitarelectric). |

These are all the names. Every instrument takes both `notes` and `chords`.

## Layers

```text Syntax
line ::= instrument ":" "{" pitched ("," pitched)* [","] "}"
```

Layers give one instrument several voices at once. Each layer is `notes` or `chords` with its keyword, and the two may be mixed. The voices start together, each repeats until all of them realign, and a note in one voice does not cut off a note in another.

The braces are everything the instrument plays: nothing else may stand on the line. A `with` goes around the line, not among the layers. At least one layer must be finite.

A body may hold one line for each instrument, so layers are how an instrument plays more than one thing in a body.

```composer-nb Example
play pattern {
  piano: { chords C | F, notes 5-3-1--- },
}
```

```composer-nb Invalid
play pattern { piano: notes 1---, piano: chords C }
```

```text Error
piano already has a line in this pattern. To layer it, put its lines in a block: piano: { ... }
```

## Settings that apply

These settings change what an instrument line sounds like. Each is defined in [Settings](/language/settings); to apply one to a single line, wrap the line in [with](/language/scope#with).

| Setting | Changes |
| --- | --- |
| [key](/language/settings#key), [mode](/language/settings#mode) | What degrees mean. |
| [octave](/language/settings#octave) | The register of pitches written without an octave. |
| [transpose](/language/settings#transpose) | The sounding pitch, in semitones. |
| [guitar.electric](/language/settings#guitarelectric) | The electric guitar's sound. |

```composer-nb Example
play pattern {
  piano: chords 1 | 4,
  with octave 2 { bass: notes 1---5--- },
}
```
