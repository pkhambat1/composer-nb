title: "Key and mode"
description: "key and mode: the root that degrees and numerals count from, and how the music is written."
---

import { Cell } from "/snippets/cell.jsx"

`key` is a note and `mode` is a setting of its own, so `set key E` then `set mode minor` is E minor. Each keeps the other: after `set mode minor`, a later `set key G` is G minor. On a [`with`](/language/settings#with), a block plays in another key.

Roman numerals and degrees count on the major scale of the key's root, whatever the mode, and `b` or `#` in front moves them a semitone. That is how a scale is described against major: natural minor is `1 2 b3 4 5 b6 b7`, and its chords are `i bIII iv v bVI bVII`. So the mode changes no pitch. It sets how the music is written: the sheet's key signature (D dorian has none, A mixolydian two sharps), how accidentals are spelt, and minor's raised 7th, which gets a sharp.

<Cell>

```composer-nb
set tempo 96
set key D
set mode dorian

pattern walk = {
  with octave 4 {
    piano: 1---2---b3---4---|5---6---b7---1'---
      |1'---b7---6---5---|4---b3---2-------|1 bars 1
  }
  guitar: chords i bIII|v bVII|i vidim|IV ii|i
  with octave 2 {
    bass: 1-------b3-------|5-------b7-------
      |1'-------6-------|4-------2-------|1 bars 1
  }
  hat: x-
  snare.cross: 2 4
  kick: 1 3
}

play walk
```

</Cell>

The tune walks D dorian up and back down, and on every second beat the chord under it has that note as its root, so all seven notes and all seven chords go by: Dm F Am C, then Dm Bdim G Em, and back to Dm. The `6` is B, the major sixth in a minor key that makes the mode dorian, and it makes the `IV`, G, a major chord. The [grooves](https://composer-nb.vercel.app/grooves/) have the same walk in each mode, lydian to locrian.
