title: "Key and mode"
description: "key and mode: the root that degrees and numerals count from, and how the music is written."
---

import { Cell } from "/snippets/cell.jsx"

`key` is a note and `mode` is a setting of its own, so `set key E` then `set mode minor` is E minor. Each keeps the other: after `set mode minor`, a later `set key G` is G minor. On a [`with`](/language/settings#with), a block plays in another key.

Degrees and Roman numerals count on the key's own scale, the mode's. In D minor, `3` is F and `6` is Bb; in D dorian, `6` is B; in D major, `3` is F#. So the same line in another mode sounds in that mode: change `set mode` and the notes change with it. A `b` or `#` in front moves a degree or numeral a semitone off the scale, as minor's raised seventh is `#7`. The mode also gives the sheet its key signature (D dorian has none, A mixolydian two sharps) and how accidentals are spelt.

<Cell>

```composer-nb
set tempo 96
set key D
set mode dorian

pattern walk = {
  with octave 4 {
    piano: 1---2---3---4---|5---6---7---1'---
      |1'---7---6---5---|4---3---2-------|1 bars 1
  }
  guitar: chords i III|v VII|i vidim|IV ii|i
  with octave 2 {
    bass: 1-------3-------|5-------7-------
      |1'-------6-------|4-------2-------|1 bars 1
  }
  hat: x-
  snare.cross: 2 4
  kick: 1 3
}

play walk
```

</Cell>

The tune walks D dorian up and back down, and on every second beat the chord under it has that note as its root, so all seven notes and all seven chords go by: Dm F Am C, then Dm Bdim G Em, and back to Dm. Not a note has a `b` or `#`: the mode makes them dorian. The `6` is B, the major sixth in a minor key, and it makes the `IV`, G, a major chord. Change `set mode dorian` to `set mode minor` and the B becomes Bb. The [grooves](https://composer-nb.vercel.app/grooves/) have the same walk in each mode, lydian to locrian.
