`key` is a note and `mode` is a setting of its own, so `set key E` then `set mode minor` is E minor. Each keeps the other: after `set mode minor`, a later `set key G` is G minor. On a [`with`](/language/settings#with), a block plays in another key.

Degrees and Roman numerals count on the key's own scale, the mode's. In D minor, `3` is F and `6` is Bb; in D dorian, `6` is B; in D major, `3` is F#. So the same line in another mode sounds in that mode: change `set mode` and the notes change with it. A `b` or `#` in front moves a degree or numeral a semitone off the scale, as minor's raised seventh is `#7`. The mode also gives the sheet its key signature (D dorian has none, A mixolydian two sharps) and how accidentals are spelt.

<Cell>

```composer-nb
chords chart = i ii|iii iv|v vi|vii i|vii vi|v iv|iii ii|i

with key D, mode dorian { play piano: chords chart }
with key D, mode minor { play piano: chords chart }
with key D, mode major { play piano: chords chart }
```

</Cell>

A digit in a chart is the chord the scale has on that degree, so one chart goes up the scale and back down in every mode, and each mode makes its own chords. In D dorian they are Dm Em F G Am Bdim C: the `iv`, G, is major, where natural minor has Gm. In D minor the same chart plays Dm Edim F Gm Am Bb C, and in D major D Em F#m G A Bm C#dim. A Roman numeral says the chord outright instead: `iv` is a major chord on the 4th degree whatever the mode, and a plain lowercase numeral takes the scale's own fifth, so `vii` is diminished in major. The [grooves](https://composer-nb.vercel.app/grooves/) have the same walk in each mode, lydian to locrian.
