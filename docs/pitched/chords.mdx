---
title: "chords"
description: "The `chords` type: a chart of chords in bars for a pitched instrument."
---

```text Syntax
chart ::= ["|"] bar ("|" bar)* ["|"]
bar   ::= slot+ | "%"
slot  ::= chord | name | call | "-" | "_"
chord ::= root [suffix] ["/" bass]
root  ::= letter ("#" | "b")* | degree | numeral
bass  ::= letter ["#" | "b"] | degree
call  ::= interval "(" chart ["," integer] ")"
```

A `chords` value is a chord chart: bars separated by `|`, each bar divided equally among its slots. It names no instrument: the [instrument line](/pitched/instruments#instrument-lines) it is written on decides what plays it.

## Where a chords value is written

| Position | Signature | Notes |
| --- | --- | --- |
| On an instrument line | `instrument ":" "chords" chart` | The `chords` keyword is required, before a name as well. |
| In a declaration | `"chords" name "=" chart` |  |
| As a function argument | `interval "(" chart ")"` |  |
| In `print`, or as a last expression | `"chords" chart`, or a `chords` name |  |

## What a chart is made of

| Form | Example | Meaning |
| --- | --- | --- |
| Chord symbol | `C`, `F#m7`, `Bb/D` | A chord named by its root letter; see [Chord symbols](/pitched/chords#chord-symbols). |
| Chord degree | `1`, `5dom7`, `b7` | A chord built on a degree of the scale; see [Chords by degree](/pitched/chords#chords-by-degree). |
| Hold | `-` | The chord sounding keeps sounding for this slot. |
| Rest | `_` | The chord sounding stops. The slot is silent. |
| Name | `home` | A declared `chords` name, in place. |
| Interval call | `fourth(home)` | The argument, moved through the scale; see [Interval functions](/functions/intervals). |
| Bar line | `\\|` | Ends a bar. Optional before the first bar and after the last. |
| Repeat bar | `%` | A whole bar: the bar before it, again. |

Slots are separated by spaces. A long chart may continue on a new line that starts with `|`.

## Bars and slots

A bar's slots share it equally, and each slot must last a whole number of sixteenth notes. A `4 over 4` bar therefore holds 1, 2, 4, 8 or 16 slots; a `3 over 4` bar 1, 2, 3, 4, 6 or 12. [every](/language/patterns#every) does not change this: chords count bars, not steps.

A chart is as long as its bars. It takes no `n*` repeats and no `...` fills.

- A chart cannot start with `-`: there is no chord to hold.
- `%` stands alone in its bar and needs a bar before it.
- In a pattern, a chart that is the same bars written out more than once is an error, with or without `%`. Write one cycle; the pattern repeats it. The same chord twice inside one bar, `C C`, is fine.

```composer-nb Example
play piano: chords C - G _ | Am F | % | G
```

```composer-nb Invalid
play piano: chords C D E
```

```text Error
A 4 over 4 bar can't be split evenly into 3. Use - to hold a chord for another slot, e.g. Am - F G
```

## Names in a chart

A name that holds exactly one chord is a slot, like a chord symbol: `home fifth(home)` is one bar of two slots. A name that holds more than one chord, or any bar line, is a whole chart: its bars stay as they are, and names written side by side follow one another as separate bars.

To make one chord a full bar under a name, keep its bar lines: `chords homeBar = |1|`.

```composer-nb Example
chords home = 1
chords turn = 4 5 | 1
play piano: chords home fifth(home) | turn
```

## Chord symbols

```text Syntax
chord ::= letter ("#" | "b")* [suffix] ["/" bass]
```

| Part | May be |
| --- | --- |
| `letter` | `A` to `G`: the root, as an absolute pitch class. The key does not affect it. |
| Accidentals | Any number of `#` or of `b` after the letter; normally one. |
| `suffix` | A quality from the [Chord symbol catalog](/pitched/chord-symbols), or one composed with [modifiers](/pitched/chords#composing-a-suffix). Without a suffix the chord is major. |
| `bass` | See [Slash bass](/pitched/chords#slash-bass). |

A 6/9 chord is written `C6/9`, and minor `Cm6/9`. That slash belongs to the quality; a bass takes a second one: `C6/9/E`.

```composer-nb Example
print(chords C Dm7 G7 Fmaj7 Bb/D C6/9)
```

```text Output
chords C(C3 E3 G3) Dm7(D3 F3 A3 C4) G7(G3 B3 D4 F4) Fmaj7(F3 A3 C4 E4) Bb/D(Bb3 D4 F4/D2) C6/9(C3 E3 G3 A3 D4)
```

## Chords by degree

```text Syntax
chord ::= ["-"] ["b" | "#"] digit+ [suffix] ["/" bass]
```

The root is a [degree](/pitched/key#degrees) of the scale in effect, in the octave in effect. All the digits belong to the root: `17` is degree seventeen and `1 7` is two chords. A suffix on a degree therefore cannot start with a digit: write `5dom7`, not `57`, and `1maj9`, `2m7`, `1M6/9`.

| Written | Quality |
| --- | --- |
| A plain degree, `2` | The triad the scale builds there: every other scale tone, three of them. |
| A degree with an accidental, `b7` | A major triad on the altered root. |
| A quality, `2M`, `1m`, `5dom7`, `7dim`, `3aug`, `1maj7` | That quality, whatever the scale. |
| A modifier alone, `1add9`, `5sus4`, `1#5` | The scale's triad, modified. |

```composer-nb Example
print(chords 1 2 5dom7 b7 1maj7 5sus4)
```

```text Output
chords 1(C(C3 E3 G3)) 2(Dm(D3 F3 A3)) 5dom7(G7(G3 B3 D4 F4)) b7(Bb(Bb3 D4 F4)) 1maj7(Cmaj7(C3 E3 G3 B3)) 5sus4(Gsus4(G3 C4 D4))
```

Lowercase Roman numerals `i` to `vii` are also roots, for degrees 1 to 7, with an optional `b` or `#` in front. A numeral is always lowercase: the mode decides major or minor, and a quality written after it overrides that (`iM`, `im`). Because a numeral has no digits, digits after it are its suffix: `v7` is the seventh chord the scale builds on degree 5. Use `dim`, `dim7` and `m7b5` with degrees and numerals; the glyphs `°` and `ø` are accepted only after a letter root.

## Composing a suffix

```text Syntax
suffix   ::= quality modifier*
modifier ::= "sus2" | "sus4" | "sus" | "add" ["#" | "b"] n | ("#" | "b") n
```

A suffix found in the [Chord symbol catalog](/pitched/chord-symbols) means exactly what the catalog lists. Any other suffix is read as a catalog quality followed by modifiers, applied left to right.

| Modifier | Effect |
| --- | --- |
| `sus2` | Replaces the third with a major second. |
| `sus4`, `sus` | Replaces the third with a perfect fourth. |
| `add n` | Adds interval `n` and nothing between. |
| `add#n`, `addbn` | Adds interval `n`, raised or lowered. |
| `#n`, `bn` | Raises or lowers interval `n`, adding it if absent. |

`n` is from 2 to 13 and counts major and perfect intervals from the chord's root, whatever the key. A later modifier of the same interval replaces an earlier one.

```composer-nb Example
print(chords Csus2add11, chords C7#5b9, chords 1sus2add11#5/4)
```

```text Output
chords Csus2add11(C3 D3 G3 F4), C7#5b9(C3 E3 G#3 Bb3 Db4), 1sus2add11#5/4(Csus2add11#5/F(C3 D3 G#3 F4/F2))
```

## Slash bass

```text Syntax
bass ::= letter ["#" | "b"] | ["-"] ["b" | "#"] digit+
```

`/bass` adds one note below the chord. A letter is an absolute pitch class. A number is a degree of the key in effect, not an interval above the chord's root; Roman numerals are not accepted here. The bass sounds in the octave below the chord. A chord takes one bass.

A chord without a slash has no added bass note: its lowest note is its root.

```composer-nb Example
print(chords C/E, chords 1/3, chords Am/G)
```

```text Output
chords C/E(C3 E3 G3/E2), 1/3(C/E(C3 E3 G3/E2)), Am/G(A3 C4 E4/G2)
```

## Voicing

Chord tones are stacked upward from the root, which sits in the [octave](/language/settings#octave) in effect. Extended chords keep their upper tones up to two octaves above the root. `guitar` and `guitar.electric` play a fretboard shape for the chord when one is known, and the stacked tones otherwise.

Every tone, and the bass, must be within MIDI 0 to 127.

## Interval calls

```text Syntax
call ::= interval "(" chart ["," integer] ")"
```

An interval call inside `chords` has type `chords` and stands wherever a slot may; a call on a whole chart stands for those bars. Every chord tone and bass moves through the scale, so the quality of the result follows the scale. Inside the argument, `%` needs a bar before it in the same argument. Accent and ghost marks do not apply to chords. The functions are defined in [Interval functions](/functions/intervals).

```composer-nb Example
chords home = 1
print(chords home fourth(home) fifth(home) octave(home, -1))
```

```text Output
chords 1(C(C3 E3 G3)) 4(F(F3 A3 C4)) 5(G(G3 B3 D4)) -7(C(C2 E2 G2))
```

## Errors

```composer-nb Invalid
play piano: chords - C
```

```text Error
This line starts with - but there's no chord to hold yet
```

```composer-nb Invalid
play piano: chords % | C
```

```text Error
% repeats the bar before it, but this is the first bar
```

```composer-nb Invalid
play piano: chords I IV
```

```text Error
"I": numerals are lowercase, and the mode makes the chord major or minor: i. To say a chord outright, write its quality after it: iM, im
```

```composer-nb Invalid
print(chords C69)
```

```text Error
"C69" isn't a chord I know
```
