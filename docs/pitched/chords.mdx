## Syntax

```text
<instrument>: chords <bar> [| <bar>] ...
```

A chord line is a chart of chords on a [pitched instrument](/pitched/instruments#instruments)'s line, with the word `chords` in front. It is valid inside a block or directly after `play`. Without `chords`, the line is read as [notes](/pitched/notes).

<Cell>

```composer-nb
play guitar: chords C - - G|Am - F G|%|F - _ -
```

</Cell>

## Bars and slots

`|` separates bars. Within a bar, the tokens are separated by spaces and divide the bar into equal slots.

| Token            | Meaning                                                        |
| ---------------- | -------------------------------------------------------------- |
| Chord symbol     | Starts the chord at this slot.                                 |
| Roman numeral    | Starts the chord on that degree of the current `key`.          |
| `-`              | Holds the previous chord for this slot.                        |
| `_`              | Silence for this slot.                                         |
| `%`              | Repeats the previous bar. Must be the only token in its bar.   |
| `chords` name    | Inserts the named bars. A bar line is implied on each side.    |

Each slot must be a whole number of sixteenth notes. A `4 over 4` bar accepts 1, 2, 4, 8 or 16 slots. Three chords in a `4 over 4` bar is an error; write `Am - F G`.

In the example above, bar 1 is C for three beats and G for one, bar 3 repeats bar 2, and bar 4 is F for two beats followed by two beats of silence.

## Chord symbols

```text
<root>[<quality>][/<bass>]
```

| Part      | Values                                                                                              |
| --------- | --------------------------------------------------------------------------------------------------- |
| `root`    | `A` to `G`, with an optional `#` or `b`.                                                            |
| `quality` | Empty for major, or a standard suffix: `m`, `7`, `maj7`, `m7`, `9`, `dim`, `aug`, `sus2`, `sus4`, `add9`, `m7b5` and others. `sus` is read as `sus4`. |
| `bass`    | A note name. Replaces the root as the lowest note.                                                  |

Examples: `C`, `Am`, `F#m`, `Bb7`, `Cmaj7`, `Dm9`, `G7sus4`, `Em7b5`, `Cadd9`, `C/E`.

## Roman numerals

```text
[b|#]<numeral>[°|o|ø][<quality>]
```

A Roman numeral names a chord by its scale degree in the current [`key`](/pitched/instruments#key). Degrees are taken from the major scale in a major key and from the natural minor scale in a minor key.

| Element          | Meaning                                              |
| ---------------- | ---------------------------------------------------- |
| `I` to `VII`     | Major chord on that degree.                          |
| `i` to `vii`     | Minor chord on that degree.                          |
| `b` or `#` prefix | Lowers or raises the root by a semitone.            |
| `°` or `o`       | Diminished. With `7`, diminished seventh.            |
| `ø`              | Half-diminished (`m7b5`).                            |
| `quality`        | Appended to the chord: `V7`, `ii7`, `Imaj7`.         |

<Cell>

```composer-nb
key C
play piano: chords I vi|IV V7|bVII IV|ii7 vii°
```

</Cell>

In C this plays `C Am`, `F G7`, `Bb F`, `Dm7 Bdim`.

## What changes how chords sound

| What                                   | Effect                                                              |
| -------------------------------------- | ------------------------------------------------------------------- |
| The line's [instrument](/pitched/instruments#instruments) | What the chords play on: `piano`, `guitar` and others. |
| [`key`](/pitched/instruments#key)       | The key that Roman numerals are read in.                           |
| [`capo`](/pitched/instruments#capo)     | Raises a guitar's chords by a number of frets.                     |
| [`octave`](/pitched/instruments#octave) | The octave of each chord's root.                                   |

See [Instruments, key and capo](/pitched/instruments), which also describes how each instrument [voices](/pitched/instruments#voicing) a chord.

## Rhythm

A chart's rhythm is its slots. `_` leaves a slot silent, so chords on the off-beats are written with silence on the beats. With eight slots in a `4 over 4` bar, each slot is an eighth note.

<Cell>

```composer-nb
pattern skank = {
  guitar.electric: chords _ Am _ Am _ Am _ Am|_ Dm _ Dm _ Dm _ Dm
  kick: 3
  hat: x-
}

play skank
```

</Cell>

Chord names do not go on the steps of a [note line](/pitched/notes).

## Repetition

| Location     | Behavior                                              |
| ------------ | ----------------------------------------------------- |
| In a pattern | The line repeats until the pattern ends.              |
| In a play    | The line plays once.                                  |

A block holds one line for each instrument. Two instruments each take a chart of their own. For chords under a tune on one instrument, the instrument's line takes a block of [layers](/pitched/notes#layers).

To play chords over drums, put the chord line and the drum lines in one pattern. See [Chords and drums together](/song/patterns#chords-and-drums-together).

## Errors

| Message                                                                                         | Cause                                         |
| ----------------------------------------------------------------------------------------------- | --------------------------------------------- |
| `Chords go on an instrument's line, e.g. piano: chords Am F`                                    | Chord symbols with no instrument.             |
| `"Am" is a chord, and these are notes. For chords, write guitar: chords Am F`                   | A chart without `chords` in front.            |
| `verse is chords, so chords goes in front of it: piano: chords verse`                           | A `chords` name without `chords` in front.    |
| `chords needs the chords after it: piano: chords Am F\|C G`                                     | Nothing after `chords`.                       |
| `"F---G---" is notes, and this line says chords. A line of notes has no word in front: piano: F---G---` | Notes after `chords`.                 |
| `A 4 over 4 bar can't be split evenly into 3. Use - to hold a chord for another slot, e.g. Am - F G` | Slot count does not divide the bar.      |
| `"Hm" isn't a chord I know`                                                                     | Unrecognized chord symbol.                    |
| `This line starts with - but there's no chord to hold yet`                                      | `-` in the first slot.                        |
| `% repeats the bar before it, but this is the first bar`                                        | `%` in the first bar.                         |
| `% stands for a whole bar, so it goes between bar lines on its own: Am F\|%`                    | `%` next to other tokens in a bar.            |
| `piano already has a line in this play. To layer it, put its lines in a block: piano: { ... }`  | Second line for one instrument in a block.    |
| `Chords play one at a time, so they can't be layered in a block. Put them on one line: piano: chords Am F\|C G` | A block after `chords` or `chords <name> =`. |
| `chords: is gone. Chords go on their instrument's line: piano: chords Am F`                     | The earlier `chords:` line.                   |
