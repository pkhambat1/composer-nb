---
title: "every"
description: "Sets the duration of one step for the statements that follow it."
---

`every` sets how long one step lasts for a statement or block. Outside `every`, a step is a sixteenth note.

## Syntax

```text
every <length> <statement>
every <length> { <statements> }
```

| Parameter | Type                                              | Description                         |
| --------- | ------------------------------------------------- | ----------------------------------- |
| `length`  | A [length](/language/numbers-and-lengths#lengths) in `steps`, `beats` or `bars` | The duration of one step.           |

`every` is valid inside a block, after `play`, and as the value of a `pattern` declaration. It goes in front of a line, not inside one.

## Step duration

| Statement           | One step lasts                    |
| ------------------- | --------------------------------- |
| `every 2 steps`     | An eighth note.                   |
| `every 3 steps`     | A dotted eighth note.             |
| `every 4 steps`     | A quarter note.                   |
| `every 1/2 steps`   | A thirty-second note.             |
| `every 1/3 beats`   | An eighth-note triplet.           |
| `every 1/6 beats`   | A sixteenth-note triplet.         |

`steps` in the length refers to the step duration of the enclosing block, so nested `every` statements multiply: `every 2 steps` inside `every 2 steps` gives quarter notes.

| Constraint | Value                                                                  |
| ---------- | ---------------------------------------------------------------------- |
| Minimum    | One twelfth of a beat.                                                 |
| Resolution | The duration must be a whole number of ticks, at 96 ticks per beat.    |

## Behavior

| Aspect        | Behavior                                                                                             |
| ------------- | ---------------------------------------------------------------------------------------------------- |
| Scope         | The step duration applies inside the `every` statement only. Lines outside it keep their own.         |
| Content       | The statements form a pattern without a name. Its lines repeat, and its duration follows the [pattern rules](/language/patterns#duration). |
| Repetition    | The pattern repeats until the containing pattern or play ends, and must fit it a whole number of times. |
| Steps         | Each step character, and each `steps` unit in a length, lasts the new duration.                       |
| Beats         | Beat positions are unchanged. A beat is always a quarter note.                                        |
| Chords        | Chord lines are unchanged. Chord slots divide the bar.                                                |

## Example

```composer-nb
time 3 over 4

pattern feet = every 3 steps {
  kick: X-XX-X--
  hat.pedal: -x--x-xx
}

play {
  snare: Xxxx
  feet
}
```

Inside `feet`, each step lasts three sixteenth notes. The eight steps of the kick and pedal lines last 24 sixteenths, which is two bars of `3 over 4`. The snare line keeps sixteenth-note steps.

## Errors

| Message                                                                                       | Cause                                         |
| --------------------------------------------------------------------------------------------- | --------------------------------------------- |
| `every takes a length, then what plays at that pace: every 3 steps { ... }`                   | No length.                                    |
| `every 3 steps needs what plays at that pace: every 3 steps { ... }`                          | Nothing after the length.                     |
| `A step can't last 1/100 beats. Try every 3 steps, or every 1/3 beats`                        | Duration below the minimum or off the tick grid. |
| `every goes in front of the line, not inside it: every 3 steps kick: x-xx`                    | `every` after an instrument's colon.          |
| `Nothing plays this. Put play in front, or give it a name: pattern slow = every 3 steps { ... }` | `every` at top level.                      |
