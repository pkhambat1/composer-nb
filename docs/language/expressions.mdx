## Numbers

```text Syntax
number  ::= term (("+" | "-") term)*
term    ::= factor (("*" | "/") factor)*
factor  ::= ["-"] (literal | "(" number ")")
literal ::= digit+ ["." digit+]
integer ::= ["+" | "-"] digit+
```

A `number` is an arithmetic expression over decimal literals. `*` and `/` bind tighter than `+` and `-`; operators of equal precedence apply left to right. Spaces between tokens are optional. There is no unary `+`, no exponent notation and no numeric names. Division by zero is an error.

An `integer` is a literal, not an expression. Positions that take an `integer` say so in their signature: repeat counts, Euclidean rhythms and the second argument of an interval function.

| Position | Takes |
| --- | --- |
| Setting values, lengths, `every`, `on bar` | `number` |
| `n*word` repeat count, `hits in steps`, interval multiplier | `integer` |

```composer-nb Example
set tempo 60*2
play piano: notes 1--- for 1/2 bars
```

Inside music the same characters have other meanings: `*` repeats a word, `/` adds a bass to a chord, `-` holds a note or negates a degree. A time signature is written with `over`, because `7/8` is the number 0.875.

## Lengths

| Unit | Meaning | Written |
| --- | --- | --- |
| Step | One character of `steps`, or one note, hold or rest of `notes`. A step lasts 1/4 beat unless [every](/language/patterns#every) changes it. | Not written: counted. |
| Beat | A quarter note, whatever the time signature. | `number "beats"`, only in `every`. |
| Bar | One measure of the time signature in effect. | `number "bars"`. |

```text Syntax
length ::= number "bars"
```

Units are always plural: `1 bars`, `1 beats`. The singular `bar` occurs only in `on bar`, which is a position, not a length.

A bar of `count over unit` lasts `count * 4 / unit` beats, which is `count * 16 / unit` steps at the default step: 16 steps in `4 over 4`, 12 in `3 over 4`, 14 in `7 over 8`.

A `length` may stand in these positions:

| Position | Meaning |
| --- | --- |
| `pattern name = length body`, `block name = length body` | The declared part lasts exactly `length`. |
| `length "pattern" body`, `length "block" body` | The inline part lasts exactly `length`. |
| `length name`, `length group` | The named pattern or the group repeats for `length`, which must hold a whole number of repetitions. A block name takes no length: a block plays once. |
| `play part "for" length` | The output lasts `length`; see [play duration](/language/play#duration). |

`steps`, `notes` and `chords` never take a length: they last as long as what is written. To make one longer, repeat a word (`8*-`) or end the line with a fill (`...-`).

## Limits

| Quantity | Limit |
| --- | --- |
| A `length` | Greater than 0, at most 64 bars. Fractions are allowed. |
| A bar position in `on bar` | A whole number from 1 to 64. |
| Lines of different lengths in a pattern | Must realign within 64 bars, or the pattern needs an explicit length. |
| One `play` | At most 600 seconds. |
| Timing resolution | 96 ticks per beat. A step lasts a whole number of ticks, at least 8 (1/12 beat). |
| Pitch | MIDI 0 to 127, after value functions and `transpose`. |
| Scale degree | -128 to 128, not 0. |
| Interval multiplier | -64 to 64. |
| Nesting | Step repeat groups 64 deep; note repeat groups and value function calls 32 deep. |
