An instrument's line holds a `notes` value. It is drawn on steps like a kit piece's line, with a note where a kit piece has its `x`.

<Cell>

```composer-nb
play piano: E4---E4---F4---G4--- | G4---F4---E4---D4---
```

</Cell>

## Instruments

| Name | Instrument |
| --- | --- |
| `piano` | Grand piano, sampled |
| `piano.electric` | Electric piano, sampled |
| `organ` | Drawbar organ, sampled |
| `pad` | Synth pad |
| `bass` | Fingered electric bass, sampled |
| `guitar` | Steel-string guitar, sampled |
| `guitar.electric` | Electric guitar, sampled. Clean or [muted](/language/settings#instrument-sound). |

## Writing notes

A note is a capital `A` to `G`, then an optional `#` or `b`, then an optional octave from 0 to 8. A note without a number is in the current [`octave`](/language/settings#capo-and-octave). Pitches are as they sound, so a guitar's low E is `E2`.

| Step | Plays |
| --- | --- |
| A note or a [degree](#degrees) | Starts the note. It sounds until the next note or `_`. |
| `^` or `~` before a note | The note accented, or soft. |
| `-` | Nothing new. A sounding note carries on. |
| `_` | Stops the note: one step of silence. |
| `\|` | Optional bar line, checked against the `time`. |

A note is one step however many characters it has, so `F---` and `F#---` are both quarter notes. Two notes never touch: a `-`, `_`, space or `|` goes between them. A space takes no step, so `E---F# E-E--` is ten steps.

In a pattern, the last note rings over the repeat until the first note or `_`. A value written as the same figure more than once is an error, because the pattern repeats it: `C2-C2-` is `C2-`.

## Degrees

A degree is a digit from `1` to `7` where a note goes, counted on the major scale of the [`key`](/language/settings#key)'s root, whatever the key's mode. A `b` or `#` in front moves it a semitone, so a scale is written as it is described against major: natural minor is `1 2 b3 4 5 b6 b7`. Degree 1 is the root in the current `octave`; `'` after the digit is an octave up for each mark, and `'` before it an octave down.

<Cell>

```composer-nb
key C
octave 4

notes major = 1---2---3---4---|5---6---7---1'---
notes minor = 1---2---b3---4---|5---b6---b7---1'---

play piano: major
play piano: minor

key F#
play piano: major
```

</Cell>

A name holds degrees, not pitches, so it is read under whichever key plays it: the last play is F# major. Letters and degrees can share a line, as a chart holds `I vi|F G`. On a kit piece's line a number is a beat, so `kick: 1 3` hits beats 1 and 3 and `bass: 1 3` plays two degrees: the line's name says which.

## Lengths

Commas split a line into parts, as on a kit piece's line. A [length](/language/overview#lengths) in front of one note holds it for that long, and in front of `rest` is silence. The length `...` is what is left of the block: `...G1` holds G1 to the end, and `...rest` is silence to the end. A line ended in `...` has no length of its own, so the other lines decide how long the block is.

<Cell>

```composer-nb
time 3 over 4

pattern waltz = {
  bass: 3 beats C2, 3 beats G1
  piano: chords _ C C|_ G G
}

play 2 bars waltz
play piano: 2 beats rest, E4---F4---, 1 bars G4
```

</Cell>

A length holds one note: `3 beats C2-E2-` is an error, since a figure is drawn on the steps. A long line continues on the next line when that line starts with `|`, and a length can follow the `|` as it follows a comma.

<Cell>

```composer-nb
notes flats = A3-Ab3-G3-Gb3-F3-E3-Eb3-D3-
  |Db3-C3-B2-Bb2-A2---, 1 beats rest

play piano: flats
```

</Cell>

## Layers

A line plays one note at a time. For notes that sound together, give the instrument a block of layers, one per line. Each layer is its own voice and repeats until they all end together. A layer can be a chart with `chords` in front, to put chords under a tune.

<Cell>

```composer-nb
key C
octave 4

play piano: {
  chords vi IV|I V
  6-------4-------|6---5---4---3---
}
```

</Cell>
