---
title: "play"
description: "The `play` statement: renders a part as sound."
---

```text Syntax
play_stmt ::= "play" part ["for" length]
```

| Operand | Type | May be |
| --- | --- | --- |
| `part` | `part` | A [line](/language/patterns#lines), a `pattern` or `block` name, `pattern { ... }`, `block { ... }`, a [group](/language/patterns#groups), an [every](/language/patterns#every), a [placed part](/language/patterns#on-bar), or a [with](/language/scope#with). |
| `length` | `length` | `number "bars"`: greater than 0, at most 64. |

Evaluates `part` under the settings in effect and produces one output. `play` is a statement: it stands at the top level of a cell or inside a top-level `with`, never inside a body.

`steps`, `notes` and `chords` are not parts. To hear one, give it a line: `play piano: notes riff`.

## What plays how often

| Part after `play` | Without `for` | With `for length` |
| --- | --- | --- |
| Line | Once. | Once, then silence. |
| `block { ... }` | Its lines once. | Its lines once in a block of that length. |
| `pattern { ... }` | One cycle: until its lines realign. | Its lines repeat for that length. |
| Pattern name | Its own length. | Repeats, cut off at `length`. |
| Block name | Its own length. | Once, then silence. |
| Group | Its parts in order, once. | Repeats as a whole, cut off at `length`. |

## Duration

```text Syntax
"for" length
```

Without `for`, the output lasts as long as the part. With `for`, the output lasts exactly `length`: whatever is still repeating or sounding is cut off there, and time the part does not fill is silent. For `pattern { ... }` and `block { ... }` written inline, `for` is the length of that pattern or block itself.

`for` only bounds the output. A named part keeps its own length, and everything inside it must still fit by its own rules.

One output may last at most 600 seconds.

```composer-nb Example
pattern groove = { kick: x--- --x-, hat: x- }
play groove
play groove for 4 bars
play pattern { kick: x---, crash: x ...- } for 2 bars
```

## Output

Each `play` produces one output: audio, and the data for the notebook's other views, which are a bar-by-bar grid, sheet music, chord names and guitar chord shapes. A cell's outputs play one after another.

## Errors

```composer-nb Invalid
play 2 bars pattern { kick: x--- }
```

```text Error
A play's duration follows its music: play groove for 2 bars
```

```composer-nb Invalid
notes riff = 1-3-
play riff
```

```text Error
riff is notes, so it goes on an instrument's line: piano: notes riff
```

```composer-nb Invalid
play piano: notes 1 ...-
```

```text Error
Every line in this play ends in ..., so nothing says how long it is. Say so: play block { ... } for 4 bars
```
