---
title: "play"
description: "The statement that renders a value to audio."
---

`play` evaluates what follows it and renders one output. It is the only statement that makes sound, and it goes at the top level of a cell.

```text
play <name, group or line> [for <number> bars]
play block { <statements> } [for <number> bars]
play pattern { <lines> } [for <number> bars]
```

```composer-nb
pattern groove = {
  kick: x---
  snare: ----x---
}

play groove
play piano: chords Am F for 2 bars
play block {
  crash: 1
  groove
} for 4 bars
```

This cell renders three outputs.

## What repeats

A play is a timeline, and its statements start together. The braces after `play` say their type, as any others do, so a bare `play { ... }` is an error. `play block { ... }` plays its statements as this table says.

| In a play | Plays |
| --- | --- |
| A line | Once. |
| A block | Once, with silence after it if the play runs longer. |
| A pattern, or a group in brackets | Repeated until the play ends. A group plays what's in it in order. |
| `every` | Repeated until the play ends. |
| `bar <n>` | In bar `n`. |

`play pattern { ... }` repeats every line in it, as any pattern does.

```composer-nb
play block {
  kick: x---
  snare: ---- x---
} for 2 bars

play pattern {
  kick: x---
  snare: ---- x---
} for 2 bars
```

The first output plays each line once, then silence. The second repeats both lines for two bars.

## Duration

Write `play groove for 2 bars` to set the whole output’s duration. The duration follows the music; `play 2 bars groove` is rejected.

Without a duration, a play lasts as long as its longest statement, and what repeats must fit that a whole number of times. With a length, it lasts exactly that long: whatever is repeating stops at the end, and silence fills any time left over. A play can't run past 10 minutes.

After braces, the length is theirs: a pattern in `play block { ... } for 4 bars` repeats to fill all four bars. A name keeps the length it was declared with, so `play accent for 4 bars` plays the block `accent` once, then silence.

## Output

- A header with the time, tempo, key, number of bars and the instruments that play.
- Audio, with a waveform to follow and seek.
- A grid of every hit and note, bar by bar. The playground can draw it as sheet music instead: the kit on a percussion staff with hands up and feet down, each instrument on a staff of its own (a guitar with its tab) in the signature of the [`key`](/pitched/key), and the sheet prints.
- The chords played. The playground draws a diagram for each.
