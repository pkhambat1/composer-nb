title: "Settings"
description: "Every setting: the value it takes, its default, its range and what it changes."
---

A setting is a name followed by a value. Settings are given to [set](/language/scope#set), which changes the rest of the cell, or to [with](/language/scope#with), which changes one pair of braces. Both statements, and the rules for where settings are in effect, are defined in [Scope](/language/scope). This page defines the settings themselves.

## Settings index

```text Syntax
setting ::= "time" number "over" number
          | "tempo" number
          | "swing" ("on" | "off")
          | "key" pitch_class
          | "mode" mode
          | "octave" number
          | "transpose" number
          | "kit" ("rock" | "synth")
          | "guitar.electric" ("clean" | "muted")
```

| Setting | Value | Default | Effect |
| --- | --- | --- | --- |
| [time](/language/settings#time) | `number "over" number` | `4 over 4` | Time signature: the length and grouping of a bar. |
| [tempo](/language/settings#tempo) | `number`, 20 to 400 | `120` | Quarter notes per minute. |
| [swing](/language/settings#swing) | `on` or `off` | `off` | Swung eighth notes. |
| [key](/language/settings#key) | `pitch_class` | `C` | The tonic that scale degrees count from. |
| [mode](/language/settings#mode) | one of 10 mode names | `major` | The scale that degrees and interval functions move through. |
| [octave](/language/settings#octave) | whole `number`, 1 to 6 | `3` | The register of pitches written without an octave. |
| [transpose](/language/settings#transpose) | whole `number`, -12 to 12 | `0` | Semitones added to every sounding pitch. |
| [kit](/language/settings#kit) | `rock` or `synth` | `rock` | The drum kit's sounds. |
| [guitar.electric](/language/settings#guitarelectric) | `clean` or `muted` | `clean` | The electric guitar's sound. |

Every `number` is an arithmetic expression; see [Numbers](/language/expressions#numbers). Value words such as `on`, `minor` and `rock` are written exactly as shown.

`time`, `tempo` and `swing` set the clock, so parts that sound together must share them. The other six settings may differ between parts that sound together; see [with](/language/scope#with).

## time

```text Syntax
"time" count "over" unit
```

| Operand | Type | May be |
| --- | --- | --- |
| `count` | `number` | A whole number of at least 1, or a sum of them such as `3+2`. Not a decimal such as `4.0`. |
| `unit` | `number` | 1, 2, 4, 8 or 16. |

Default: `4 over 4`. A bar holds `count` notes of length 1/`unit`, and may last at most 8 whole notes (`count / unit` is at most 8).

A `count` written as a sum groups the bar: `3+2 over 8` is five eighth notes felt as three then two, and the sheet music beams them that way. Any other expression is a single group.

Changing `time` changes the length of a bar. It does not change the length of a beat, which is always a quarter note, or of a step.

```composer-nb Example
set time 3+2+2 over 8
play pattern { kick: x-----x---x--- }
```

```composer-nb Invalid
set time 7/8
```

```text Error
/ is division, so 7/8 is the number 0.875, not a time. Write set time 7 over 8
```

## tempo

```text Syntax
"tempo" number
```

Default: `120`. Range: 20 to 400, fractions allowed. Quarter notes per minute, whatever the time signature: a beat lasts `60 / tempo` seconds.

## swing

```text Syntax
"swing" ("on" | "off")
```

Default: `off`. With `on`, each beat is split two thirds and one third instead of in half, so the off-beat eighth lands on the last triplet of the beat. Steps between move in proportion. Swing changes playback only: the grid and the sheet music stay straight.

## key

```text Syntax
"key" pitch_class
pitch_class ::= ("A" | "B" | "C" | "D" | "E" | "F" | "G") ["#" | "b"]
```

Default: `C`. The tonic: the pitch that degree `1` names. A key is a note only. It has no octave and no quality: A minor is `key A` with `mode minor`.

Changing `key` moves scale degrees and interval functions. Notes and chords written with letters keep their pitch. See [Key and mode](/pitched/key).

```composer-nb Invalid
set key Am
```

```text Error
A key is a note: set key A, then set mode minor
```

## mode

```text Syntax
"mode" mode
mode ::= "major" | "minor" | "dorian" | "phrygian" | "lydian" | "mixolydian"
       | "locrian" | "harmonicMinor" | "melodicMinor" | "wholeTone"
```

Default: `major`. The scale built on the key. It decides which pitch each degree names, the quality of each degree's chord, where interval functions land, and the key signature and spelling on the sheet. `ionian` and `aeolian` are not mode names: they are `major` and `minor`. The scales are listed in [Modes](/pitched/key#modes).

## octave

```text Syntax
"octave" number
```

Default: `3`. Range: a whole number from 1 to 6. The register of every pitch written without an octave of its own. Octaves change at C, and `C4` is middle C. Degree `1` is the tonic in this octave and higher degrees continue upward: under `key A`, `octave 3`, degree `1` is A3 and degree `5` is E4.

A note written with its own octave, such as `E2`, ignores this setting. To move an existing value by octaves, use the [octave function](/functions/intervals#function-index), which is relative.

```composer-nb Example
with octave 2 { print(1, C, E4, chords 1) }
```

```text Output
notes 1(C2), C(C2), E4
chords 1(C(C2 E2 G2))
```

## transpose

```text Syntax
"transpose" number
```

Default: `0`. Range: a whole number from -12 to 12. Semitones added to every sounding pitch of notes, chords and chord basses, after everything else is resolved.

Written names stay as written: note names, chord symbols and guitar chord shapes are unchanged, and `print` shows the sounding pitches in parentheses. On a guitar, `transpose 4` therefore sounds like the written shapes with a capo at the fourth fret. Kit pieces are not transposed, and setting a transpose other than 0 in a cell that plays only kit pieces is an error.

```composer-nb Example
with transpose 2 { print(1, chords C) }
```

```text Output
notes 1(D3)
chords C(D(D3 F#3 A3))
```

## kit

```text Syntax
"kit" ("rock" | "synth")
```

Default: `rock`. The sounds of all kit pieces. `rock` is a sampled acoustic kit; `synth` is synthesized. Kit-piece names and step notation are the same for both. See [Drum kit](/drums/kit).

## guitar.electric

```text Syntax
"guitar.electric" ("clean" | "muted")
```

Default: `clean`. The sound of the `guitar.electric` instrument; `muted` is palm-muted. No other instrument has a choice of sounds.
