## Requirements

| Requirement | Version                                                                 |
| ----------- | ----------------------------------------------------------------------- |
| Python      | 3.9 or later                                                            |
| `anywidget` | 0.9 or later. Installed as a dependency.                                |
| `ipython`   | 7.23 or later. Installed as a dependency. Tab completion requires 8.6.  |
| Front end   | JupyterLab, Jupyter Notebook 7, VS Code or Google Colab                 |
| Network     | Required for the `piano` and `guitar` sounds and the `rock` drum kit, which load samples on first use. |

## Install

```bash
pip install composer-nb
```

## Load

```python
%load_ext composer_nb
```

Loading the extension registers the [`%%music`](/python/music-magic) cell magic and its Tab completion in the current kernel. It must be run once per kernel session.

## Module contents

```python
import composer_nb
```

| Name                                    | Kind     | Description                                              |
| --------------------------------------- | -------- | -------------------------------------------------------- |
| [`Song`](/python/song)                  | Class    | A cell's source, with an optional link to another song.  |
| [`MusicWidget`](/python/music-widget)   | Class    | The notebook widget that parses and plays sources.       |
| `__version__`                           | `str`    | The installed package version.                           |
| `load_ipython_extension(ipython)`       | Function | Called by `%load_ext composer_nb`.                       |

## Execution model

The Python package does not parse or render source. `Song` and `%%music` pass source text to `MusicWidget`, and the widget's JavaScript parses it and renders audio in the browser. Errors in the source are shown in the cell output and are not raised as Python exceptions.
