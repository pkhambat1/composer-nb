---
title: "Song"
description: "A cell's source as a Python object."
---

```python
class composer_nb.Song(source, *, after=None, name=None)
```

A `Song` holds one cell of composer-nb source and an optional link to the song it continues from. [`%%music`](/python/music-magic) creates one for each cell. Displaying a `Song` in a notebook renders its player.

## Parameters

<ParamField path="source" type="str" required>
  The composer-nb source for one cell.
</ParamField>

<ParamField path="after" type="Song | None">
  The song to continue from. The new song starts from the settings and declarations that `after` ended with. Keyword-only. Defaults to `None`.
</ParamField>

<ParamField path="name" type="str | None">
  A label for the song. Shown in the output header and used as the WAV file name. Keyword-only. Defaults to `None`.
</ParamField>

## Attributes

<ResponseField name="source" type="str">
  The source passed to the constructor.
</ResponseField>

<ResponseField name="after" type="Song | None">
  The song this one continues from.
</ResponseField>

<ResponseField name="name" type="str | None">
  The song's label.
</ResponseField>

<ResponseField name="chain" type="list[str]">
  Read-only. The sources from the start of the `after` chain to this song, in order. The last element is this song's source.
</ResponseField>

## Methods

### widget()

```python
Song.widget() -> MusicWidget
```

Returns a new [`MusicWidget`](/python/music-widget) for the song, with `sources` set to `chain`.

### Display

`Song` implements `_repr_mimebundle_`. A notebook front end renders it as the widget. Plain-text renderers receive `repr(song)`.

```python
repr(Song("play chords: C", name="intro"))        # "Song('intro')"
repr(Song("play chords: F", after=intro))         # "Song(after=intro)"
```

## Exceptions

| Exception    | Raised by     | Condition                                               | Message                                                |
| ------------ | ------------- | ------------------------------------------------------- | ------------------------------------------------------ |
| `TypeError`  | Constructor   | `source` is not a `str`.                                | `source must be a str, not int`                        |
| `TypeError`  | Constructor   | `after` is not a `Song` or `None`.                      | `after must be a Song, not str`                        |
| `ValueError` | `chain`, `widget()`, display | The `after` links form a cycle.          | `songs can't continue from each other in a loop`       |

Errors in the source do not raise. They are shown in the rendered output.

## Examples

### Linked songs

```python
from composer_nb import Song

intro = Song("tempo 75\nsound guitar\nplay chords: Am E7|G D", name="intro")
verse = Song("play chords: F C|Dm E7", after=intro, name="verse")
verse
```

`verse` plays at tempo 75 on guitar. The link is to the `intro` object, so it is independent of cell order.

### Generated source

```python
from composer_nb import Song

bars = ["A7", "D7", "A7", "A7", "D7", "D7", "A7", "A7", "E7", "D7", "A7", "E7"]
Song("sound epiano\nplay chords: " + "|".join(bars))
```
