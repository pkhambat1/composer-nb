title: "%%music"
description: "Cell magic that plays a cell of composer-nb source."
---

## Syntax

```text
%%music [name] [after <name>]
<source>
```

| Argument       | Required | Description                                                                                      |
| -------------- | -------- | ------------------------------------------------------------------------------------------------ |
| `name`         | No       | Stores the cell as a [`Song`](/python/song) in the notebook namespace under this name. Must be a valid Python identifier and not a Python keyword. |
| `after <name>` | No       | Starts the cell from the state that the named cell ended with: its settings and declarations. The named cell must have been run. |

Requires `%load_ext composer_nb`. See [Installation](/python/installation).

## Behavior

| Step | Action                                                                                      |
| ---- | ------------------------------------------------------------------------------------------- |
| 1    | Looks up `after` in the notebook namespace, if given.                                       |
| 2    | Creates `Song(source, after=..., name=...)`.                                                |
| 3    | Assigns the song to `name` in the notebook namespace, if given.                             |
| 4    | Returns the song. The notebook displays it as the cell's output.                            |

A cell without a name is played and not stored.

## State between cells

A cell starts from the default settings unless it names another cell with `after`. The link is by name, so the result does not depend on cell position or on the order in which cells were run.

```composer-nb
%%music intro
tempo 75
capo 2
sound guitar
chords riff = Am E7|G D
play chords: riff
```

```composer-nb
%%music verse after intro
play chords: F C|Dm E7 riff
```

`verse` plays at tempo 75 on guitar with a capo at fret 2, and can use `riff`. The output header lists the inherited settings: `from intro: tempo 75, sound guitar, capo 2`.

A setting or declaration in `verse` applies to `verse` and to cells that continue from it. It does not change `intro`.

## Tab completion

Inside a `%%music` cell, Tab completes:

| Position                         | Completions                                                              |
| -------------------------------- | ------------------------------------------------------------------------ |
| `%%music name `                  | `after`                                                                  |
| `%%music name after `            | Names of songs in the namespace.                                         |
| Start of a line, top level       | Settings, types, `play`.                                                 |
| Start of a line, inside a block  | Instrument names, pattern names, `bar`, `every`, settings, types.        |
| After `sound` or `kit`           | The accepted values.                                                     |
| After `ride.`, `hat.`, `snare.`  | The variations of that drum.                                             |
| On a drum line                   | `steps` names. After a number, the units. After a unit, `rest`.          |
| On a `chords` line               | `chords` names.                                                          |
| After `play`                     | Pattern names and instrument names.                                      |

Names declared in the cells that the current cell continues from are included. Python completions are suppressed inside the cell.

## Errors

The magic raises `IPython.core.error.UsageError` in these cases.

| Message                                                                                             | Cause                                             |
| --------------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| `Usage: %%music [name] [after <name>]`                                                              | Arguments do not match the syntax.                |
| `'2x' can't be a cell name. Use letters, digits and underscores, like intro or verse_2.`            | A name that is not a valid identifier.            |
| `intro can't continue from itself.`                                                                 | `%%music intro after intro`.                      |
| `intro hasn't been run yet. Run its cell first.`                                                    | `after` names something not in the namespace.     |
| `intro is a int, not a %%music cell.`                                                               | `after` names a value that is not a `Song`.       |

Errors in the source are reported in the cell output. See [Errors and limits](/reference/errors).
