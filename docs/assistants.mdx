## Connection

Point an MCP client at this HTTP endpoint:

```text Syntax
https://composer-nb.vercel.app/mcp
```

The [composer-nb plugin](https://github.com/pkhambat1/composer-nb/tree/main/plugin) adds skills for writing cells, grooves, practice routines and theory explanations. Running the server locally is described in the [MCP server README](https://github.com/pkhambat1/composer-nb/tree/main/mcp).

## Tools

| Tool | Purpose |
| --- | --- |
| `parse` | Checks a cell, optionally continuing from the cells in `after`. Returns errors with line numbers, the settings and names in effect, printed values, and a grid of what each `play` sounds. |
| `render` | Exports checked music as a sheet-music PNG, a MIDI file or ABC notation. |
| `library` | Searches the bundled grooves. |
| `reference` | Returns one reference topic, or all of them with `topic: "all"`. |

Reference topics and library entries are also MCP resources. In clients that support MCP Apps, `parse` shows an editable cell with a player.

## Reference topics

| Category | Topic IDs |
| --- | --- |
| Index | `symbols`, `grammar` |
| Language | `overview`, `values`, `scope`, `expressions` |
| Settings | `settings`, `key` |
| Value types | `steps`, `notes`, `chords`, `chord-symbols` |
| Composition | `patterns`, `play` |
| Functions | `intervals`, `print` |
| Kit and instruments | `kit`, `instruments` |

## Workflow

Read the topic for what is being written, write a short cell, and call `parse`. Pass the cells above it as `after` when it uses their names or settings. Fix every error before showing the cell or calling `render`.
