composer-nb is a typed language for writing music as text. A notebook cell holds settings, declarations and statements; `play` renders music and `print` displays values. For each construct, this reference gives its syntax, the type of every operand and what may be written there, its meaning, and its errors.

## Anatomy of a cell

Every position in a cell has a type, and the type decides what else may be written there.

```composer-nb Example
set tempo 96
steps pulse = x--x--x-
play pattern {
  kick: pulse,
  hat: x-,
  piano: chords C G,
}
```

| Written | What it is | What else may stand there |
| --- | --- | --- |
| `set tempo 96` | A [set](/language/scope#set) statement. `tempo 96` is a `setting`. | Any of the nine [settings](/language/settings#settings-index). |
| `steps pulse = x--x--x-` | A [declaration](/language/values#declarations) of a `steps` name. | A declaration of any of the five [value types](/language/values#value-types). |
| `play` | The [play](/language/play) statement. It takes a `part`. | `print`, to display values instead. |
| `pattern { ... }` | A [pattern](/language/patterns#pattern): a `part` whose lines repeat. | `block { ... }`, a pattern or block name, a group `( ... )`, or a single line; see [Parts](/language/patterns#parts). |
| `kick` | A `kit_piece`. | Any of the 14 [kit pieces](/drums/kit#kit-pieces). |
| `pulse` | A `steps` value, by name. | Anything of type [steps](/drums/steps): step words, a repeat, a Euclidean rhythm, a fill, layers. |
| `x-` | A `steps` value, written out. | The same. |
| `piano` | An `instrument`. | Any of the 6 [instruments](/pitched/instruments#instruments). |
| `chords C G` | A [chords](/pitched/chords) value, with its type keyword. | `notes` and a [notes](/pitched/notes) value, or layers of both. |

## Notation

### Syntax

Syntax is given as grammar rules in boxes labelled Syntax.

```text Syntax
play_stmt ::= "play" part ["for" length]
```

| Notation | Meaning |
| --- | --- |
| `name ::= ...` | A rule: `name` is written as the right-hand side. |
| `"play"` | Literal text, written exactly as shown, without the quotes. |
| `part` | Another rule, or one of the categories in [Types](/language/values). |
| `[ x ]` | `x` is optional. |
| `x*`, `x+` | `x` zero or more times; `x` one or more times. |
| `x \\| y` | Either `x` or `y`. |
| `( x y )` | Grouping. |

The language itself uses braces, parentheses, bar lines and stars, so in a rule those characters are literal only inside quotes. Every rule is collected in the [Grammar](/reference/grammar).

### Operands

Under a rule, a table lists each operand with its type and what may be written for it. A type is one of the five [value types](/language/values#value-types), `steps`, `notes`, `chords`, `pattern` and `block`, or one of the [other categories](/language/values#other-categories-used-in-signatures) such as `kit_piece`, `instrument`, `number` and `part`.

Functions are given as signatures: `name(parameter: type = default) -> result type`.

### Boxes

| Label | Contents |
| --- | --- |
| Syntax | A rule or signature. Not code to run. |
| Example | A complete cell that runs as shown. Every example in this reference is checked against the language. |
| Output | What the example above it prints. |
| Invalid | A cell that is an error. |
| Error | The error the cell above it reports. |
