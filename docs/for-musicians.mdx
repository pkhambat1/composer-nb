## Evaluate a cell

Open the [playground](https://composer-nb.vercel.app), type into a cell and press Shift+Enter. The cell's statements run from top to bottom. Each `play` adds a player; `print` and a final value expression add a row of values.

```composer-nb Example
play piano: notes C4
```

## Read the output

A `play` output can be heard and viewed as a bar-by-bar grid or as sheet music. Chords also show their names and, for guitars, their shapes.

If a cell has an error, it produces no output. Each error names its line; fix it and evaluate again.

## Continue across cells

Settings changed with `set` and names declared at the top level carry into the cells below. A later cell may declare an inherited name again. Anything inside a `with` or a body stays there. See [Scope](/language/scope).

## Find a construct

Hover a built-in word, such as `third`, `tempo` or `piano`, for its syntax, meaning, an example and a link to this reference. Errors are underlined as you edit; hover an underline for its explanation, or press F8 to move to the next error. Changing a setting or definition also rechecks the cells below it.

Start from the [reference contents](/#contents) or the [Symbol index](/reference/symbols). The [Grammar](/reference/grammar) lists all syntax in one place.
