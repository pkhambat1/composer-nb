Four [settings](/reference/settings) change how a [`chords` line](/chords/lines) sounds. None of them affects drums.

| Setting             | Value                 | Default | Effect                                             |
| ------------------- | --------------------- | ------- | -------------------------------------------------- |
| [`sound`](#sound)   | Sound name            | `piano` | The instrument the chords play on.                 |
| [`key`](#key)       | Key name              | `C`     | The key that Roman numerals are read in.           |
| [`capo`](#capo)     | Whole number, 0 to 12 | `0`     | Raises guitar chords by that many frets.           |
| [`octave`](#octave) | Whole number, 1 to 6  | `3`     | The octave of each chord's root.                   |

## sound

```text
sound <name>
```

The sound that `chords` lines play on.

| Value    | Source                                                             |
| -------- | ------------------------------------------------------------------ |
| `piano`  | Sampled grand piano. Samples load from the network.                |
| `epiano` | Synthesized electric piano.                                        |
| `organ`  | Synthesized organ.                                                 |
| `pad`    | Synthesized pad with a slow attack.                                |
| `bass`   | Synthesized bass.                                                  |
| `guitar` | Sampled steel-string guitar. Samples load from the network. Chords are played as fretboard shapes where a shape is known. |

A drum name is not a valid value. Drums are written as [drum lines](/drums/lines).

## key

```text
key <note>[m]
```

The key that [Roman numeral chords](/chords/lines#roman-numerals) resolve against. `note` is a letter `A` to `G` with an optional `#` or `b`. A trailing `m` selects a minor key.

| Example  | Key            |
| -------- | -------------- |
| `key C`  | C major        |
| `key Am` | A minor        |
| `key Bb` | B flat major   |
| `key F#m`| F sharp minor  |

## capo

```text
capo <fret>
```

A whole number from 0 to 12. With `sound guitar`, each chord sounds `fret` semitones higher than written. Chord labels and diagrams keep the written shape.

`capo` has no effect on other sounds. A cell that sets a capo above 0 and plays, but plays no guitar chords, reports `capo only works on guitar. Add sound guitar`. An inherited capo does not trigger this error.

<Cell>

```composer-nb
sound guitar
capo 2
play chords: Am E7|G D
```

</Cell>

## octave

```text
octave <number>
```

A whole number from 1 to 6. Sets the octave of each chord's root. The bass note is placed one octave below the root. Guitar chords played as fretboard shapes ignore this setting.

## Voicing

| Sound          | Voicing                                                                                                    |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| All but guitar | Chord tones stacked upward from the root in the current [`octave`](#octave), within two octaves. The bass note sounds one octave below. |
| `guitar`       | The fretboard shape for the chord where one is known, shifted up by [`capo`](#capo). Otherwise as above. |

## Errors

| Message                                                                        | Cause                                             |
| ------------------------------------------------------------------------------ | ------------------------------------------------- |
| `sound is one of: piano, epiano, organ, pad, bass, guitar`                     | Unknown sound.                                    |
| `key looks like C, Am, Bb or F#m`                                              | Unknown key.                                      |
| `capo is a fret number from 0 to 12`                                           | Value out of range or not whole.                  |
| `octave is a number from 1 to 6`                                               | Value out of range or not whole.                  |
| `capo only works on guitar. Add sound guitar`                                                   | `capo` set in a cell that plays no guitar.    |
