## Syntax

```text
chords: <bar> [| <bar>] ...
```

A `chords` line is an instrument line. It is valid inside a block or directly after `play`. It plays on the current [`sound`](/chords/sound#sound).

<Cell>

```composer-nb
sound guitar
play chords: C - - G|Am - F G|%|F - _ -
```

</Cell>

## Bars and slots

`|` separates bars. Within a bar, the tokens are separated by spaces and divide the bar into equal slots.

| Token            | Meaning                                                        |
| ---------------- | -------------------------------------------------------------- |
| Chord symbol     | Starts the chord at this slot.                                 |
| Roman numeral    | Starts the chord on that degree of the current `key`.          |
| `-`              | Holds the previous chord for this slot.                        |
| `_`              | Silence for this slot.                                         |
| `%`              | Repeats the previous bar. Must be the only token in its bar.   |
| `chords` name    | Inserts the named bars. A bar line is implied on each side.    |

Each slot must be a whole number of sixteenth notes. A `4 over 4` bar accepts 1, 2, 4, 8 or 16 slots. Three chords in a `4 over 4` bar is an error; write `Am - F G`.

In the example above, bar 1 is C for three beats and G for one, bar 3 repeats bar 2, and bar 4 is F for two beats followed by two beats of silence.

## Chord symbols

```text
<root>[<quality>][/<bass>]
```

| Part      | Values                                                                                              |
| --------- | --------------------------------------------------------------------------------------------------- |
| `root`    | `A` to `G`, with an optional `#` or `b`.                                                            |
| `quality` | Empty for major, or a standard suffix: `m`, `7`, `maj7`, `m7`, `9`, `dim`, `aug`, `sus2`, `sus4`, `add9`, `m7b5` and others. `sus` is read as `sus4`. |
| `bass`    | A note name. Replaces the root as the lowest note.                                                  |

Examples: `C`, `Am`, `F#m`, `Bb7`, `Cmaj7`, `Dm9`, `G7sus4`, `Em7b5`, `Cadd9`, `C/E`.

## Roman numerals

```text
[b|#]<numeral>[°|o|ø][<quality>]
```

A Roman numeral names a chord by its scale degree in the current [`key`](/chords/sound#key). Degrees are taken from the major scale in a major key and from the natural minor scale in a minor key.

| Element          | Meaning                                              |
| ---------------- | ---------------------------------------------------- |
| `I` to `VII`     | Major chord on that degree.                          |
| `i` to `vii`     | Minor chord on that degree.                          |
| `b` or `#` prefix | Lowers or raises the root by a semitone.            |
| `°` or `o`       | Diminished. With `7`, diminished seventh.            |
| `ø`              | Half-diminished (`m7b5`).                            |
| `quality`        | Appended to the chord: `V7`, `ii7`, `Imaj7`.         |

<Cell>

```composer-nb
key C
play chords: I vi|IV V7|bVII IV|ii7 vii°
```

</Cell>

In C this plays `C Am`, `F G7`, `Bb F`, `Dm7 Bdim`.

## Settings for chords

| Setting                         | Effect                                                            |
| ------------------------------- | ----------------------------------------------------------------- |
| [`sound`](/chords/sound#sound)   | The instrument the chords play on: `piano`, `guitar` and others. |
| [`key`](/chords/sound#key)       | The key that Roman numerals are read in.                         |
| [`capo`](/chords/sound#capo)     | Raises guitar chords by a number of frets.                       |
| [`octave`](/chords/sound#octave) | The octave of each chord's root.                                 |

See [Sound, key and capo](/chords/sound), which also describes how each sound [voices](/chords/sound#voicing) a chord.

## Repetition

| Location     | Behavior                                              |
| ------------ | ----------------------------------------------------- |
| In a pattern | The line repeats until the pattern ends.              |
| In a play    | The line plays once.                                  |

A block holds one `chords` line. Chords cannot be layered in a block of their own.

To play chords over drums, put the `chords` line and the drum lines in one pattern. See [Chords and drums together](/song/patterns#chords-and-drums-together).

## Errors

| Message                                                                                         | Cause                                         |
| ----------------------------------------------------------------------------------------------- | --------------------------------------------- |
| `Chords go on a chords: line, e.g. chords: Am F`                                                | Chord symbols with no instrument.             |
| `A 4 over 4 bar can't be split evenly into 3. Use - to hold a chord for another slot, e.g. Am - F G` | Slot count does not divide the bar.      |
| `"Hm" isn't a chord I know`                                                                     | Unrecognized chord symbol.                    |
| `This line starts with - but there's no chord to hold yet`                                      | `-` in the first slot.                        |
| `% repeats the bar before it, but this is the first bar`                                        | `%` in the first bar.                         |
| `% stands for a whole bar, so it goes between bar lines on its own: Am F\|%`                    | `%` next to other tokens in a bar.            |
| `chords already has a line in this play. Chords play one at a time, so put them all on one line` | Second `chords` line in a block.             |
| `Chords play one at a time, so they can't be layered in a block. Put them on one line: chords: Am F\|C G` | A block after `chords:` or `chords <name> =`. |
