---
title: "steps"
description: "The `steps` type: what one kit piece plays, written one character per step."
---

```text Syntax
steps_expr  ::= step_seq | step_layers
step_seq    ::= step_item+ [step_fill]
step_item   ::= step_word | name | repeat | euclid | "|"
step_word   ::= ("x" | "^" | "~" | "d" | "-")+
repeat      ::= integer "*" (step_word | name | "(" step_item+ ")")
euclid      ::= integer "in" integer
step_fill   ::= "..." (step_word | name)
step_layers ::= "{" steps_expr ("," steps_expr)* [","] "}"
```

A `steps` value is a row of steps for one kit piece. It has no pitch and names no kit piece: the [kit-piece line](/drums/kit#kit-piece-lines) it is written on decides what plays it.

## Where a steps value is written

| Position | Signature | Notes |
| --- | --- | --- |
| On a kit-piece line | `kit_piece ":" steps_expr` | No `steps` keyword after the colon. |
| In a declaration | `"steps" name "=" steps_expr` | Must be finite: no `step_fill`. Layers hold only step words, names and nested layers. |
| In `print`, or as a last expression | `"steps" step_seq`, or a `steps` name | Must be finite. |

## What a steps value is made of

| Form | Example | Meaning |
| --- | --- | --- |
| Step word | `x-^-` | One character per step; see [Step characters](/drums/steps#step-characters). |
| Name | `pulse` | The steps of a declared `steps` name, in place. |
| Repeat | `3*x-`, `2*(x- --^-)`, `2*pulse` | The word, name or group, that many times in a row. |
| Euclidean rhythm | `3 in 8` | That many hits spread evenly over that many steps. |
| Bar line | `\\|` | Ends the current bar, padding missing time with silence. |
| Fill | `...x-` | Last on the line: repeats its word to the end of the surrounding part. |
| Layers | `{ x---, --^- }` | Several rows merged into one. |

Items are separated by spaces. Spaces take no time and are otherwise ignored between step words, so `x--- x---` and `x---x---` are the same eight steps; group by beat for reading. A name, repeat or Euclidean rhythm must be set off by spaces.

## Step characters

| Character | Meaning |
| --- | --- |
| `x` | A hit. |
| `^` | An accented hit. |
| `~` | A ghost (soft) hit. |
| `d` | A double stroke: two hits in one step, the second half a step after the first. |
| `-` | An explicitly written silent step. Unfilled bar space is silent automatically. |

Two kit pieces restrict these. `snare` does not take `~`: the snare's ghost notes are their own kit piece, `snare.ghost`. Every hit on `snare.ghost` is already soft, so it takes `x` and `d` but neither `~` nor `^`.

## Length

Each character lasts one step. A step is a sixteenth note (1/4 beat) unless [every](/language/patterns#every) changes it, so a `4 over 4` bar is 16 steps.

| Form | Length in steps |
| --- | --- |
| Step word | Its number of characters. |
| Name | The length of the named value. |
| `n*item` | `n` times the length of `item`. |
| `hits in steps` | `steps`. |
| `\\|` | Silence through the next bar boundary, if needed. |
| Fill | None of its own; see [Fills](/drums/steps#fills). |
| Layers | The shortest length at which all finite layers realign. |

In a pattern, `kick: x---` loops every four steps. In a block, the kick plays once and the rest of the bar is silent. A finite `steps` value may be at most 64 bars long.

## Repeats

```text Syntax
repeat ::= integer "*" (step_word | name | "(" step_item+ ")")
```

| Operand | Type | May be |
| --- | --- | --- |
| `integer` | `integer` | A literal of at least 2. |
| Right-hand side | `steps` | A step word, a `steps` name, or a parenthesized group of items. Groups nest. |

Plays its right-hand side `integer` times in a row. Parentheses in steps always need a count: `(x-)` alone is an error. To repeat a Euclidean rhythm, group it: `2*(3 in 8)`.

`2*x- 2*(-^ --)` is the twelve steps `x-x- -^-- -^--`.

```composer-nb Example
play({ kick: 2*x- 2*(-^ --), hat: 12*x })
```

## Euclidean rhythms

```text Syntax
euclid ::= hits "in" steps
```

| Operand | Type | May be |
| --- | --- | --- |
| `hits` | `integer` | From 1 to `steps`. |
| `steps` | `integer` | From `hits` to 64. |

A row of `steps` steps with `hits` hits spread as evenly as possible, starting on a hit.

| Written | Is the same as |
| --- | --- |
| `3 in 8` | `x--x--x-` |
| `5 in 8` | `x-xx-xx-` |
| `2 in 5` | `x-x--` |
| `4 in 16` | `x---x---x---x---` |

```composer-nb Example
play(pattern({ kick: 3 in 8, hat: x- }))
```

## Fills

```text Syntax
step_fill ::= "..." (step_word | name)
```

A fill is the last item on a line. The steps before it play once; then its word repeats until the surrounding part ends, cut short if it does not fit. For silence to the end of a block, simply end the line. In a pattern, end the line with `|` for silence to the next bar boundary.

A fill has no length of its own, so something else must say when the part ends: another line that is finite, or an explicit length. A value with a fill cannot be named or printed.

```composer-nb Example
play({ kick: x, hat: x-x- x-x- x-x- x-x- })
```

```composer-nb Example
play({ snare: ---- x--- ...x }) for 1 bars
```

```composer-nb Invalid
steps intro = x ...-
```

```text Error
Bars automatically fill with silence; remove the rest-to-end fill
```

## Layers

```text Syntax
step_layers ::= "{" steps_expr ("," steps_expr)* [","] "}"
```

Merges several rows into one row for the same kit piece. Each finite layer repeats at its written length until all layers realign. That point is the length of the result and must come within 64 bars. Where two layers both hit a step, the later layer's hit is kept. Silence never removes a hit.

Layers are the whole value: nothing else may stand beside the braces on a kit-piece line. To put layers in a row with other steps, name them first. A layer may itself be layers. On a kit-piece line, a layer may end in a fill, and at least one layer must be finite.

In a `steps` declaration, a layer is a row of step words and names, or nested layers. Declare a repeat or Euclidean rhythm under its own name before layering it.

```composer-nb Example
steps backbeat = { x-------, ----^--- }
print(backbeat)
play(pattern({ snare: backbeat, hat: x- }))
```

```text Output
steps x^
```

```composer-nb Invalid
play pattern { kick: { x--- } x }
```

```text Error
A block is everything kick plays, so nothing goes beside it. To put steps in a row with a block, name it: steps fig = { ... } and kick: x--- fig
```

## Explicit repetition

In a pattern, `kick: x---` gives one kick every four steps. Add a trailing bar line, `kick: x--- |`, for one kick per bar. Use a counted repeat to build a longer figure, for example `kick: 3*x--- xx--`. In a block, a counted repeat specifies how many times the figure plays.

```composer-nb Example
play(pattern({ kick: 4*x--- })) for 2 bars
play({ kick: x--- })
```

## Errors

```composer-nb Invalid
play pattern { snare: --~- }
```

```text Error
"~": the snare's ghost notes go on a line of their own: snare.ghost: --x-
```

```composer-nb Invalid
play pattern { kick: x--- 2 beats }
```

```text Error
Kit lines use step words, not lengths: repeat with 4*x- or fill the block with ...x-
```

```composer-nb Example
play({ kick: x--- x- | })
```

The remaining ten steps are silent.
