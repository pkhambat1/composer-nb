A [kit piece](/drums/kit)'s line holds a `steps` value: one character per step, and a step is a sixteenth note. A bar of `4 over 4` is 16 steps.

<img src="/images/sheet-to-code.svg" alt="One bar of a rock beat on a drum staff: hi-hat eighth notes, snare on 2 and 4 with accents, kick on 1, 3 and the and of 3. Below it, the hat, snare and kick lines in code, with each character under the note it plays." />

<Cell>

```composer-nb
play block {
  hat: ^-x- x-x- x-x- x-x-,
  snare: ---- ^--- ---- ^-x-,
  kick: x--- ---- x-x- ----,
}
```

</Cell>

## Characters

| Character | Plays |
| --- | --- |
| `x` | A hit. |
| `^` | An accent. |
| `~` | A ghost note. The snare's ghost notes go on `snare.ghost`, as `x`. |
| `d` | Two thirty-second notes. |
| `-` | Nothing. |
| `\|` | Optional bar line, checked against the `time`. |

Spaces are ignored, so steps can be grouped by beat. A `steps` value is as long as its characters: `x--x---` is seven steps.

In a pattern, write a repeating figure once: `hat: x-`, never `hat: 8*x-`. A block plays a finite sequence once, so repeats are useful there.

## Repeats

The same bar can be counted as words and repeats:

<Cell>

```composer-nb
play block {
  hat: 8*x-,
  snare: 4*- ^ 7*- ^ 3*-,
  kick: x 7*- x-x 5*-,
}
```

</Cell>


A kit line is words separated by spaces. `n*w` repeats a word `n` times, where `n` is a whole number of at least 2. `8*-` is eight silent steps; `4*x-` is four copies of `x-`. Parentheses group words: `2*(^-x- x-x-)`. Groups can nest. Use spaces within a kit line; a comma ends its entry in braces.

<Cell>

```composer-nb
play block {
  snare: 8*- dd 6*-,
  hat: 4*x- 8*-,
}
```

</Cell>

## Rests and lengths

`-` is the only silence on a kit line. Count silent steps with a repeat: `8*-`, rather than a beat list, a length or `rest`. A step is a quarter of a beat unless [`every`](/language/patterns#every) changes it. Pitched instruments keep their note lengths, commas and `rest`.

A final `...w` repeats the word `w` to the end of the containing block. `...-` is silence to the end, and `...x-` repeats `x-` to the end. Nothing may follow it. The line then has no length of its own: the other lines decide how long the block is, and what comes before the `...` plays once each time through.

<Cell>

```composer-nb
set time 9 over 8
set tempo 100

pattern manias = {
  hat.open: x---,
  hat: --x-,
  kick: x--x-x---x--x-xx--,
  snare: -------x-,
  snare.ghost: -xx ...-,
}

play manias for 4 bars
```

</Cell>

This is *Circle of Manias* by Porcupine Tree. The hats are 4 steps long, the kick 18 and the snare 9, so the pattern is 36 steps, and the ghost notes come back at the top of each pass.

## Hits spread over steps

`3 in 8` is three hits spread as evenly as eight steps allow: `x--x--x-`, the tresillo. It is one word in the line, separated from neighboring words by spaces, and a `steps` name can hold it.

<Cell>

```composer-nb
steps tresillo = x--x--x-

play block {
  kick: tresillo,
  hat: x 3*- x 3*-,
  snare: 8*- x-xx-xx-,
}
```

</Cell>

## Layers

A block after a kit piece's colon holds layers, separated by commas, with an optional trailing comma, and evaluates to one `steps` value. Each layer repeats until they all end together. Where two layers hit the same step the lower one wins, and a `-` never overrides a hit. The block is the whole value, so nothing goes beside it: `hat: x--- { ... }` is an error. To put steps in a row with a block, name it: `steps fig = { ... }` and `hat: x--- fig`.

<Cell>

```composer-nb
play snare.ghost: {
  --x-,
  ------------ddd-,
}
```

</Cell>

This evaluates to `--x---x---x-ddd-`.
