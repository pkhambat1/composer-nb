## Syntax

```text
<setting> <value>
```

A setting is a reserved word followed by its value. It takes no `=` and no `:`. Writing `tempo = 90` or `tempo: 90` is an error.

## Summary

| Setting              | Value                            | Default    | Applies to               |
| -------------------- | -------------------------------- | ---------- | ------------------------ |
| [`time`](/song/time-and-tempo#time)      | `<count> over <unit>`            | `4 over 4` | Bar length               |
| [`tempo`](/song/time-and-tempo#tempo)    | Number, 20 to 400                | `120`      | Playback speed           |
| [`key`](/pitched/instruments#key)        | Key name                  | `C`        | Roman numeral chords     |
| [`capo`](/pitched/instruments#capo)      | Whole number, 0 to 12     | `0`        | Chords on a guitar's line |
| [`octave`](/pitched/instruments#octave)  | Whole number, 1 to 6      | `3`        | Chord voicing, and notes with no octave |
| [`kit`](/drums/lines#kit)        | `rock` or `synth`                | `rock`     | Drum lines               |

Each setting is described with what it applies to: [Time and tempo](/song/time-and-tempo), [Instruments, key and capo](/pitched/instruments) and [Kit](/drums/lines#kit).

The instrument a line plays on is not a setting. It is the line's name: `guitar: chords Am F`. See [Instruments](/pitched/instruments#instruments).

## Scope

A setting applies from the line where it is written. At top level it lasts to the end of the cell and is part of the state passed to other cells. Inside a block it is local to the block. A pattern uses the settings in effect where it is played. See [Scope](/reference/program-structure#scope).

When a cell starts from another cell's state, its output header lists the inherited settings that differ from the defaults.

## Errors

These apply to every setting. The errors for one setting's value are listed on its page.

| Message                                                                        | Cause                                             |
| ------------------------------------------------------------------------------ | ------------------------------------------------- |
| `tempo is a setting, not a name, so it takes no =: tempo 90`                   | `=` after a setting.                              |
| `tempo is a setting, not an instrument, so it takes no colon: tempo 90`        | `:` after a setting.                              |
| `tempo needs a value after it, e.g. tempo 90`                                  | No value.                                         |
