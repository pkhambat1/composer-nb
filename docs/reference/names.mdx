## Syntax

```text
<type> <name> = <value>
```

A declaration binds a name to a value. The type is required and is written in front of the name.

## Types

| Type      | Value                                    | Where the name is accepted                                        |
| --------- | ---------------------------------------- | ----------------------------------------------------------------- |
| `steps`   | Steps for one drum                       | On a [drum line](/drums/lines), and in other `steps` values.   |
| `notes`   | One line of notes for a pitched instrument | On a [note line](/pitched/notes), and in other `notes` values. |
| `chords`  | One or more bars of chords               | On a [chord line](/pitched/chords) after `chords`, and in other `chords` values. |
| `pattern` | A block, a sequence of patterns, or a single statement | On a [sequence line](/song/patterns#sequence-lines), and after `play`. |

A name holds only its declared type and is accepted only where that type is accepted. Both directions are checked: the value must match the declared type, and each use must match the position.

## steps

```text
steps <name> = <steps>
steps <name> = { <layer> ... }
```

The value is anything a drum line accepts after its colon: a run of steps, parts with lengths, a list of beats, other `steps` names, or a block of layers.

<Cell>

```composer-nb
steps pair = ^-x-
steps burst = 2 beats rest, dd, 1.5 beats rest
steps backbeat = 2 4
steps ghosts = {
  --x-
  ------------ddd-
}

play {
  hat: pair pair
  snare: backbeat
  snare.ghost: ghosts
}
```

</Cell>

A list of beats is converted to one bar of steps under the `time` in effect at the declaration.

## notes

```text
notes <name> = <notes>
```

The value is one line of notes: runs of notes and other `notes` names. See [Note lines](/pitched/notes).

<Cell>

```composer-nb
notes riff = E---F#E-E--
notes turn = riff A---G---F#-
play guitar.electric: riff turn
```

</Cell>

A `notes` value cannot be a block, and takes no lengths. Notes that sound together are written as [layers](/pitched/notes#layers) on the instrument's line.

## chords

```text
chords <name> = <bars>
```

The value is a chart: anything a [chord line](/pitched/chords) accepts after `chords`. When the name is used, its bars are inserted as whole bars: a bar line is implied before and after the name.

<Cell>

```composer-nb
chords verse = Am E7|G D
play piano: chords verse verse F C
```

</Cell>

A `chords` value cannot be a block. On an instrument's line a `chords` name goes after the word `chords`, as a written chart does.

## pattern

```text
pattern <name> = [<length>] { <statements> }
pattern <name> = <sequence>
pattern <name> = [<length>] <statement>
```

Declaring a pattern does not play it. The lines and names in the body are checked at the declaration, so those errors are reported even if the pattern is never played. Duration errors are reported when the pattern is played. See [Patterns](/song/patterns).

<Cell>

```composer-nb
pattern beat = {
  kick: x---
  hat: x-
}
pattern fill = 1 bars snare: xxxx
pattern song = beat beat fill

play song
```

</Cell>

## Names

| Rule                                 | Applies to         |
| ------------------------------------ | ------------------ |
| A letter followed by letters and digits. No underscores. | All types |
| Not a [reserved word](/reference/program-structure#reserved-words). | All types |
| Not `x` followed by digits, such as `x2`. | All types      |
| Lowercase only.                      | `steps`, `notes`, `chords`  |
| At least two characters.             | `steps`, `notes`, `chords`  |
| Not a Roman numeral from `i` to `vii`. | `steps`, `notes`, `chords` |

A name must be declared above the line that uses it. Declaring a name again replaces the earlier value, including a value of a different type.

## Errors

| Message                                                                                   | Cause                                              |
| ----------------------------------------------------------------------------------------- | -------------------------------------------------- |
| `Say what pair is. Put its type in front: steps pair = ^-x-`                              | No type. The name is still bound, with the inferred type. |
| `steps pair needs = before what it holds: steps pair = ^-x-`                              | No `=`.                                            |
| `steps pair = needs something after the =`                                                | No value.                                          |
| `"Am" is a chord, and pair is steps. For chords, write chords pair = Am F`                | Value does not match the declared type.            |
| `"F---" is notes, and pair is steps. For notes, write notes pair = F---`                  | Notes declared as `steps` or `chords`.             |
| `That's a pattern, not steps. Write pattern pair = ...`                                   | A block or sequence declared as `steps`, `notes` or `chords`. |
| `A name holds one line of notes. Notes that play together go in a block on the instrument's line: piano: { ... }` | A block declared as `notes`. |
| `verse is chords, so it goes on a line like piano: chords verse, not on a drum's`         | `chords` name on a drum line.                      |
| `riff is notes, so it goes on a line like piano: riff, not on a drum's`                   | `notes` name on a drum line.                       |
| `pair is steps, so it goes on a drum's line, not on piano's`                              | `steps` name on a pitched instrument's line.       |
| `verse is chords, so chords goes in front of it: piano: chords verse`                     | `chords` name on a line without `chords` in front. |
| `riff is notes, and the rest of this line is chords. A line plays one or the other`       | `notes` name in a chart.                           |
| `beat is a pattern, so it goes on a line of its own, not on an instrument's line`         | `pattern` name on an instrument line.              |
| `"fill" isn't defined above. Name it first: steps fill = x-x-`                            | Name used before its declaration.                  |
| `bars already means something, so pick another name`                                      | Reserved word used as a name.                      |
| `kick is an instrument, so it takes a colon: kick: x-`                                    | Instrument used as a name.                         |
| `Names for steps, notes and chords are lowercase: steps pair = x-`                        | Uppercase letter in a `steps`, `notes` or `chords` name. |
| `Names for steps, notes and chords need at least two letters, because single letters are steps` | One-character name.                          |
