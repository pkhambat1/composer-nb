## Functions

The [interval functions](/functions/intervals) share one signature and move every pitch through the active scale.

| Function | Moves by |
| --- | --- |
| `unison` | Nothing. |
| `second`, `third`, `fourth`, `fifth`, `sixth`, `seventh` | 1 to 6 scale positions. |
| `octave`, `eighth` | 1 octave. |
| `ninth`, `tenth`, `eleventh`, `twelfth`, `thirteenth`, `fourteenth` | 1 octave and 1 to 6 scale positions. |
| `fifteenth` | 2 octaves. |

| Function | Effect |
| --- | --- |
| [extend](/functions/extend) | Applies one chord suffix to every chord in a chart. |

## Symbols by context

The same character can mean different things in different places.

| Symbol | In steps | In notes | In chords | Elsewhere |
| --- | --- | --- | --- | --- |
| `x` `d` | Hit, double stroke. |  |  |  |
| `^` | Accented hit. | Accent on the next note. |  |  |
| `~` | Ghost hit. | Soft next note. |  |  |
| `-` | Silence. | Hold; before a degree at the start of a word, a negative degree. | Hold; before a degree, a negative degree. | Subtraction or negation in a `number`. |
| `_` |  | Rest. | Rest. |  |
| `\\|` | Bar check. | Bar line; bar check inside `every`. | Bar line. | At the start of a line: continues the statement above. |
| `%` |  |  | Repeats the bar before. |  |
| `*` | Repeat: `3*x-`. | Repeat: `2*(1 3)`. |  | Multiplication in a `number`. |
| `...` | Fill. | Fill. |  |  |
| `/` |  |  | Bass note, or part of `6/9`. | Division in a `number`. |
| `#` `b` |  | Sharp, flat: after a letter, before a degree. | Sharp, flat; also in suffixes. |  |
| `( )` | Repeat group. | Repeat group; call arguments. | Call arguments. | A group of parts; arithmetic grouping. |
| `{ }` | Layers. |  |  | A body; an instrument's layers. |
| `,` | Between layers. |  |  | Between entries, settings and arguments. |
| `:` |  |  |  | Joins a kit piece or instrument to what it plays. |
| `=` |  |  |  | Joins a declared name to its value. |
| `//` |  |  |  | Comment to the end of the line. |
